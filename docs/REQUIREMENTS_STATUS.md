新增固定案例覆盖独立规则的原话和身份校验、人工优先、事务回滚与缓存；前端语义用例覆盖状态轴、范围版本、时间冲突和视图折叠，真实浏览器通过临时合成库验证交互。没有实现的用例不能因现有测试通过而视为通过。完整 B 组的工具版本、运行归属及真实全量 kill -9 验收尚未完成；A 组完整研究图和折叠语义仍待落实。D 组已验证守护进程不运行时 spool 积压、提示确认前 SIGKILL、实际 rg-hook 静默 exit 0、独立快照消费和备份恢复；固定案例包含两个 worktree 的 index 不变、超时、原目录删除和缺失对象拒绝，仍不代表全部 B/D 组通过。

## 已知限制

- 模型需照抄窗口的字节范围与完整原话；字节错位、未声明对象、非法关系或无范围会被严格拒绝。错误结果不入库，覆盖账本仍保留缺口。
- 不可拆分且超预算的工具组会进入人工队列，不能把它标为已处理。
- 工作集按直接 ID、标签 FTS、同文件路径、本会话先前候选排序；不匹配的对象不作为无关回填。显式 `--scope` 采用完整字段和值完全相等的筛选，模型增删范围字段会被拒绝。不指定范围时仍保留多范围检索线索，不能据此声称同范围选择已完成。
- 文件路径仅规范化分隔符和相对路径写法，尚未实现跨 worktree 与相对/绝对路径的统一身份映射。
- 延续窗口的未携带上下文记录在 `jobs` 的 `context_gap` 通知中；完整上一回合放不下时保留缺口并进入人工队列。128k 配置的真实合成测试不是满窗口提取质量评估。
- 真实试点材料仅保存于仓库外的本地作业目录，不进入测试 fixtures、Git 或远程接口。
- 链接只给模型一侧原文，另一侧是结构化卡片；这会限制可判断关系的数量。模型返回 none 时不会补造关系。概览的语义正确性尚未证明，校验器只保证引用的记录 ID 属于输入、格式合法及标记完整。
- 链接调度的 `--limit` 只限制本次新任务/重试，重跑会扫描候选对并跳过已完成项；它不是大型项目的索引分页性能保证。自动化已验证 66 对跨两页、重启恢复、新增对象和失败对不阻塞后续页；尚未在完整 Atlas 项目测量调度耗时。
- 原文遮盖保持严格规则；只有程序输入中规定的标识符位置保留原值。同名字段出现在原文、范围等自由文本中仍遮盖。项目级临床正则已另行实现；结构 ID 保护仍不允许自由文字冒用例外。
- 监控可通过 health CLI 和健康界面使用。利用率按阶段统计，片段占比按项目与片段 ID 去重；校验拒绝与引用失败分别显示。旧运行没有尝试账本时显示缺失，不能拿新尝试的比率代表全部历史；费用按 token 额度显示，不推算货币价格。
- 自动确认只识别限定形式的完整声明，不对全部自然语言作语义承诺；未识别语句仍留在人工队列。发生时间缺失、同一时刻动作冲突与范围不同不会由界面悄悄消解。
- 研究图最多返回 2000 条记录，部分图和隐藏候选时禁止折叠。折叠是可展开的视图，不修改原图；同修订展开恢复原 ID/关系/位置，组内重要历史和边界证据可查；影响传播和完整物理产物版本 diff 暂不支持；证据页已有工具报告文本或补丁的有界差异。Python wheel 不含静态资源，部署需另行构建并通过 --web-dir 指定目录。
- 追加事件使用持久片段计划，已完成内容只作上下文，晚到回复/工具结果不重复提取旧决定。候选/无候选结果与计划完成状态原子提交，中断后先恢复覆盖再继续未完成窗口。人工失败默认保留，显式 `extract --retry-failed` 重试；模型、预算、范围和人工审核变化仍会重新核对。旧库只继承精确匹配且有项目证明的完整缓存前缀；证明不足可能重新生成候选，不能推断未记录的片段计划。本地仅加载新事件、上一真实回合及对应工具调用；元数据与计划清单仍按会话读取，尚未做大型项目性能验收。
- 显式尝试 ID 保证两个 worker 交错时的记录归属；同会话提取、同项目概览/链接和同模型任务已有系统进程互斥。事务内防止同一成功运行重复入库，完整待入库响应可恢复后重新做语义校验。Linux 子进程终止已验证锁释放、恢复与未知用量保留；Windows 分支仍待目标平台验收。版本 11 已增加单数据目录提取调度器，版本 12 已自动串接关联/概览与文件恢复；包括领取归属、固定截止事件、系统锁接管与 UTC 恢复；没有安装系统常驻服务，退出后仍需启动。持续队列的实际 SIGKILL 合成案例不替代 M2 的全部真实采集验收。

- 扫描轮询与 spool 消费只处理显式来源及既有 import 路径，真实本机全量双导入尚未执行。4 MiB 以上提示和符号链接保留原件并报告未消费；未知提示原件进对象库，不被当作会话证据。health 的 ingest 反映回执和待处理数量，不是进程存活证明。钩子入口、示例和影子快照已实现，没有安装到用户客户端，完整运行输入输出版本映射尚未生成；消费 SIGKILL 合成用例不替代完整 M2 验收。
- 手工引擎基准为 20 次、p95 1426 ms、全部成功，按根目录保留 async 模式；未实测实际客户端的完整事件调用链。外部客户端强杀钩子、无效根目录、存储不可写等情况下，原件或错误类名不构成完整快照失败账本。钩子的大文件只记元数据，后台现已计算当前普通文件的完整 SHA256 并保留读取窗口；没有复制大文件正文，不能回推旧快照字节或运行输入。嵌套仓库未捕获，不能把 partial 快照当成全部输入版本的直接证据。Windows 原生平台、实际工具版本及真实规模摘要性能仍待验证。
- 前端健康统计分别保留全库与当前项目口径；queued/running 不证明进程存活，重叠快照缺口不推算成功数量。字段或利用率未知不能补零；合成浏览器验收的统计种子不证明实际快照引擎或客户端成功。

- L1 从已复制原件离线派生，版本 8 升级不补造旧运行。观察与编辑记录追加保存，派生和队列状态同事务提交；缺项目/调用/唯一执行器归属则等待，失败显式重试。请求无结果不是失败，stdout 退出码文字不是运行元数据；同一调用 ID 冲突或退出码冲突显示未知。Claude 候选文本摘要不代表物理文件字节；无完整前后内容的补丁不拼接当前文件，当前文件与最近快照也不推定为旧运行 I/O。API 每事件最多 20 个运行、每运行 100 个观察、20 个编辑、40 个版本，返回部分清单标记；差异正文每份及每事件合计最多 64000 UTF8 字节，每份最多 2000 行，超限不可展示而非截断为完整。运行命令最多展示 8000 UTF8 字节，标记预览及完整字节数；完整命令留在原始对象。尚未完成全部工具包装、跨根身份及真实全量 M2 验收。
