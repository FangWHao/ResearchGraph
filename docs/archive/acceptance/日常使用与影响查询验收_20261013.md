日期：2026-10-13。按用户要求集中补功能，只运行相关检查；完整后端与浏览器回归交由推送后的现有 CI。本机 Windows／WSL／Linux 与桌面浏览器是使用场景。

## 本次功能

- `client-install`：将两种客户端的项目技能与 MCP 配置合并到唯一登记的工作区。保留其它配置及 TOML 注释，损坏、歧义、链接或同名冲突拒绝覆盖；检查不写客户端文件，重复安装字节相同。所有文件预检后逐文件原子发布，中途失败保留已发布文件，可重新运行接续；配置完成与客户端实际启用分别报告。
- `start`：一次启动界面、来源扫描及 spool 消费、离线派生和文件处理。明确加 `--extract` 后运行已有提取、关联及概览队列，继续执行项目外发许可、真实 token 计数、128k 默认输入预算和每日额度。三个后台进程独立运行，每轮关闭数据库；控制管道断开后退出，监督器接续实际退出的工作进程。未安装系统常驻服务。
- `impact` 与 `GET /api/impact`：从对象或文件版本查询下游核对项及关系路径。固定项目、完整范围、发生／获知截止及修订；确认关系与候选、报告依赖分开，`same_topic` 等非依赖关系不传播，比较汇合仅沿选中输入传播。两集合独立分页，达到深度或数量上限明确不完整；不改任何科研状态，不证明实际 I/O 完整性。
- 详情中的“下游影响”折叠区：记录、文件版本和文件运行图均可访问，无新增主导航；多个内容版本分别打开固定历史详情，分页及迟到响应保留读取条件。
- 原生 Windows Codex 钩子：固定系统 PowerShell 执行编码参数及隔离解释器，支持含中文、空格、引号和 shell 符号的工作区；不改个人设置或信任。

## 发现并修复的问题

初次 Windows 检查有两项失败：测试读取中文 TOML 沿用了 CP936，以及频繁状态读取阻止原子替换。后者的错误处理中再次写回执，导致工作进程退出，缓冲 stdin 的守护线程又触发解释器退出故障。修复为显式 UTF-8、状态读取共享删除权限、辅助回执失败隔离及非缓冲控制管道读取。最终保持原八秒断言，实际占用等待、释放后继续、空闲锁释放和父进程退出均通过；没有增加跳过或放宽超时。

首轮浏览器缺少 libasound，两个场景启动失败；使用本机已有浏览器依赖后通过。首次前端 pnpm 不在 PATH、首次 Windows 安装早于 wheel 构建完成等执行失败均不算通过。
