# 原生 Windows 快照、完整摘要与本地导出验收

日期：2026-10-11。依据执行版 §2、§7.5–7.7、§8.1–8.2、§10、§11，以及用户“按自己的思路做”的自主开发授权。普通 NTFS 文件不再依赖 Windows 缺失的 POSIX 目录标志；同时修复 POSIX 导出父目录变化后错误报告成功。数据库仍为26，不增加迁移。

## 当前实现

- Windows 从卷根逐级打开目录，子路径相对已有句柄解析；不跟随父目录重解析点，正文只接受普通磁盘文件，拒绝额外数据流。路径被替换时仍读取原打开目录，最终身份检查使结果作废。基线来自实际目录句柄的卷和128位文件身份，避免打开后路径已经变化的竞态。
- 中文路径和 CRLF 原字节进入独立影子仓库；不修改真实工作区 index，不复制被忽略项或超限大文件。大文件仍只记元数据，完整摘要在后台顺序读取，`current_file` 不证明旧快照或实际运行输入。
- Windows 实际路径 `stat` 和 fd `fstat` 的旧 `ctime` 不同。缓存与快照改用原生 `ChangeTime`，保留原完整读取窗口；同大小和 mtime、内容变化时重新计算，不持有 SQLite 写事务或复制正文。
- Windows 本地 ZIP 独占创建、刷新并相对已打开目录改名，已有或并发出现的目标不能覆盖。失败按本次创建的句柄删除；POSIX 发布前后核对全部祖先，清理时核对本次 inode，不能删除其他程序替换的文件。Windows 返回继承 ACL 的事实，不声称设置了0600。导出仍只读，11个成员中的10个正文摘要均经物理解包验证。

接口依据：[NtCreateFile](https://learn.microsoft.com/en-us/windows/win32/api/winternl/nf-winternl-ntcreatefile)、[FILE_ID_INFO](https://learn.microsoft.com/en-us/windows/win32/api/winbase/ns-winbase-file_id_info)、[FILE_BASIC_INFO](https://learn.microsoft.com/en-us/windows/win32/api/winbase/ns-winbase-file_basic_info)、[NtSetInformationFile](https://learn.microsoft.com/en-us/windows-hardware/drivers/ddi/ntifs/nf-ntifs-ntsetinformationfile)。

## 公开案例及失败证据

全部测试使用公开合成资料，复制到本机独立临时目录，不读取完整真实会话、不调模型、不删除真实项目。新文件 `tests/golden/test_native_files.py` 共20项；其中三项使用固定公开影子Git输入，复用既有完整摘要、缓存与并发事务的全部断言。Windows同时运行41项存储／清除／占用案例，共61项，无跳过。Linux完整golden继续运行原来的三项计时快照准备案例。

旧安装包运行最初9项为9 failed in1.46s，退出1；缺少 Git、POSIX目录标志等问题实际复现。实现过程中原生接口相对改名、访问位、旧ctime含义和句柄基线的失败均保留；不是重试随机测试直到通过。原生目录基线的最后红灯为1 failed／19 passed in6.22s，确证先打开句柄、随后替换路径时不能以新路径身份作基线。POSIX 导出目录改名原实现为2 failed／12 passed in4.81s，退出1，已加入固定案例。

真实 NTFS junction 无需管理员权限，另有已打开空目录原地设置重解析点的实际系统调用；必须阻止外部正文进入读取。导出期间若 Windows 因独占子文件而拒绝父目录改名，测试核对实际拒绝、临时文件清理与外部文件保留，不将其冒充成功改变了目录。读取中的目录变化亦允许操作系统直接拒绝，但必须失败且数据库与外部正文不变。

本机原生符号链接创建实际报 WinError1314，未提权；末级符号链接元数据分支按系统接口实现，本批没有物理验证该分支。网络共享、其他文件系统和断电目录持久性也未由普通 NTFS 合成测试证明。
