# 文件版本与后台摘要界面验收

本轮按用户授权由前端子 agent 负责页面，父 agent 负责真实后台实现、接口验收、源码复核和最终图片查看。基线 b5a9b78 的 46 项前端相关文件先做本地恢复备份；合成种子在 tests/frontend_server.py，未读取真实会话或研究文件。

## 页面行为

新增“文件版本”导航，按当前项目分页读取 /api/versions，每页 25 条，支持精确绝对路径筛选。不会读取当前文件正文或执行路径文字。筛选、分页、项目和鉴权代次绑定回包，停止等待与请求序号共同保护；项目缺失或不一致拒绝整页显示，迟到结果和旧 401 不覆盖新页面。

来源分类同时核对 source、representation、algo。快照字节、链接目标文字、当前文件完整 SHA256、工具报告文本和未知来源分别呈现，工具报告的候选或确认状态不会使它变成物理字节。版本记录不证明运行实际输入输出，当前文件观察不能绑定发现快照当时的字节。

观察显示实际完整读取开始/结束及本次入库时间；缓存复用保留原读取窗口和 cached_from。接口只返回最近三条，观察总数与部分标记分别保留；数量、标记或上限矛盾提示缺口，不推定完整。任意 details 正文不显示，路径及诊断只作文字。真实纳秒签名超过浏览器安全整数时无法精确展示，拒绝显示舍入后的“原记录”。

健康页新增四项版本/观察数、五项后台任务状态和四项快照发现状态。全部按项目显示，与已有全库采集计数分开；缺字段不补零，running 只是账本，不证明进程存活。版本、任务、缓存观察和发现数量不能相加推断完整文件数。

新增十项语义单测覆盖来源不提升、链接内容边界、缓存/版本身份矛盾、精确路径、分页与缺项目拒绝、观察数量矛盾、纳秒整数解析损失及未知健康字段。新增七个浏览器案例覆盖实际 HTTP 只读及图不变、25/8 两页、特殊符号路径纯文本、缓存读取时间不被入库时间覆盖、项目切换与空结果、13 项健康统计、失败重试/401/重新鉴权、矛盾及未知字段、无法中止的旧项目和旧鉴权回包。

专项版本及健康浏览器曾输出 11 passed in 10.8s；随后补整数精度行为，由最终全部 54 个浏览器案例验证，早期 56/54 单测与较早图片不替代最终 57/54 结果。初次 build 失败为窄 Pick 类型与已有 L1 测试对象不兼容，调整兼容函数参数而不删除测试；之后最终类型检查和构建通过。
