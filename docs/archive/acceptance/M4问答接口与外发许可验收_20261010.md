## 接口与权限

服务启动时从参数或环境读取模型地址、模型名与凭据；不配置模型仍支持本地检索。默认输入 128000 token、输出 4000，共用现有日额度。浏览器只能提交项目、问题、完整范围、发生与获知截止、条数、原文窗口及预期版本；不接受地址、密钥、模型或预算覆盖，回答也不返回服务地址和凭据。

| 接口 | 行为 |
|---|---|
| GET `/api/qa/options?project=项目ID` | 项目、记录版本、模型配置状态与外发许可；只读 |
| POST `/api/qa/retrieve` | 有界检索；只读，不调用计数或模型 |
| POST `/api/qa/preview` | 同一检索的实际遮盖输入、程序遮盖标志与摘要；只读 |
| POST `/api/qa/allow-remote` | 主动许可、有效来源、预览摘要及预期版本全部核对后打开项目许可 |
| POST `/api/qa/answer` | 复用 qa 执行器；无原文零调用，失败保留来源，不创建研究 claims |
| POST `/api/qa/disable-remote` | 按项目和预期版本撤回许可，保留历史与缓存 |

研究文本整体带 rg-context，前端只解析 JSON 数据；来源文字、HTML 和回答均作为文字显示。所有接口继续要求本机 Host、同源和启动令牌。

预览与生成共用输入准备函数，显示遮盖后的问题、记录和窗口。许可摘要绑定实际发送资料、模型配置与检索请求，事务中重新核对；新增原文即使不改变 claims 版本，也可能令摘要失效。没有有效来源不能授权，改变问题、范围、条数、模型或记录后的旧预览不能开启许可。

沿用整个项目的 remote_model_allowed，明确涵盖远程计数、自动提取、问答及新增资料。撤回后，后续生成和缓存读取先检查许可；已经发出的请求可能继续处理。页面停止等待只取消浏览器等待，不宣称取消服务端或提供方执行。日常检索和候选阅读不要求先人工审核。

模型实际完整请求计数、窗口核验、额度、互斥、缓存、截断和污染作废合同不变。预览展示研究输入字段与样例，提供方指令和 schema 也纳入完整请求计数。引用校验只证明 ID 和引文属于本次遮盖后的原文，不证明自由解释正确。

## 合成测试与修复

新增 23 项 HTTP 固定案例覆盖只读库、无外发时零计数/生成、主动预览授权、撤回后缓存拒绝、旧预览、跨项目、Host/Origin/令牌、未配置与无来源、浏览器覆盖拒绝、日额度、坏模型输出、实际隐私遮盖输入一致、新原文未改版本时的摘要失效、本地模型及配置隐私。原 CLI 问答增加 1 项：模型把程序的 records 字段当原文引文时必须拒绝，保留检索材料和无效运行记录。

初次专项发现样例回执误按会话编号写入项目回执表，已按真实 schema 修正；类型检查发现问题可能为空，补明确类型验证。独立安装包验证后，父 agent 复查发现回答元数据沿用 CLI 的 provider 地址，新增 HTTP 不返回地址的调用选项及回归验证。所有修复保留现有引用校验，不放宽模型输出合同。

前端真实 HTTP 主链与明确模拟的异常边界分别记录在[前端问答验收](前端有界问答验收_20261010.md)。父 agent 实看桌面和 390 宽的预览/回答四张截图，来源、引文、主动许可、模型解释及缺口边界可见；原文 HTML 显示成文字。对象内窗口与来源文件行的字节位置分别标明。
