# 前端与本地 API 验收

日期：2026-10-09。依据 §2、§9–§11，以及用户明确要求前端子 agent 的授权。前端源文件由子 agent 开发，主 agent 核对并修正范围、分页与汇合语义后统一验收。

## 当前可用行为

- 项目切换与问题首页：问题、方案、尝试与发现可打开记录及其证据；按当前采用、暂缓、拒绝等分组，关系和卡片严格匹配完整范围。
- 复核队列：按会话/片段分组，左侧高亮原文、右侧显示结构化记录。支持 C 确认、X 驳回、E 修改、上下切换、审核状态筛选和分页；预计耗时按每条 30 秒显示为估计值。
- 片段批量确认：取齐所有 API 分页，每页核对 revision，然后在单个事务中复核整个集合。211 条合成候选跨 50 条界面页及 200 条 API 页全部确认；没有只处理第一屏。单次超过 2000 条明确拒绝，需人工分批。
- 人工修改：校验结构和原文摘要，追加人工 confirmed 替换记录和 edit 审核，不修改原 claim、证据或 L0。相同对象/类型/范围的新模型候选显示已有有效人工确认与差异。
- 决定时间线：保留提出、采用、暂缓、拒绝、撤回、再次采用以及被驳回候选；发生时间和入库时间分别展示。发生时间缺失不推断当前采用，同一瞬间的相反决定显示冲突，时区写法不同也不会绕过冲突判断。
- 健康页与检索：展示来源最后导入、游标滞后、来源缺失/截短、全库坏行/未知类型/未归属会话、当前项目覆盖缺口及其分页、压缩点、调用用量和告警。未建立钩子失败账本时显示未知。搜索使用字面量，返回长度受限。
- 证据窗口：按原始 UTF-8 字节切分 before/quote/after，程序验证摘要；上下文最多前后各 5 条。标明来源位置和窗口未展示的部分，源文件删除后已复制原文仍能打开。相关产物只列版本元数据，内容 diff 缺失明确显示。
- 研究图：React Flow + ELK，节点颜色只表示审核，采用、证据与运行单列。范围分别建节点；缺少同范围端点时保留关系 ID 供打开，禁止跨范围回退。汇合语义严格同范围，多条记录提示逐条核对，不任意挑成当前事实。
- 过程组：只改变可展开视图，要求单入口单出口、每个节点从入口可达并能到达出口，保留内部节点/关系证据及边界关系。部分图、隐藏候选或缺少端点时拒绝折叠；same_topic 不充当语义输入。

## 本地服务与写入边界

HTTP 服务基于标准库，只监听 127.0.0.1，无 host 配置。每次启动生成随机令牌，浏览器链接仅在片段中携带令牌，取得后清除；后续请求使用 Authorization。API 同时核对 Host、Origin 和 Sec-Fetch-Site，不开放 CORS。静态文件解析后必须仍位于构建目录，目录穿越与符号链接越界被拒绝；响应禁止缓存、外部嵌入和来源泄漏，访问日志不记录查询、引用或令牌。

读取请求使用独立连接和数据库快照。SQL 参数绑定，查询字段长度、页长和原文窗口受限。写入 JSON 最大 65536 字节，人工身份不能为空且不接受 rule/model 冒充；批量复核先查全部记录和版本，然后原子追加。过期版本返回 409，不存在或已有修改版的成员不会造成部分成功。接口不提供命令执行能力。

查询接口为 projects、claims/单条详情、evidence、search、health 和 graph。写入接口为 review 与单条 edit。`serve` 默认打开问题页，`review --open` 带 `?view=review` 直接打开复核队列。

## 构建、视觉检查与部署

首页 JS 约 272 kB，图组件约 184 kB；ELK 独立懒加载约 1431 kB，进入研究图才加载。调高构建警告阈值不代表 ELK 体积变小，真实大项目布局性能尚未测量。

主 agent 查看了桌面问题页、桌面研究图与 390 像素宽手机截图；问题页等待数据加载后截图，图节点范围文本改为完整行省略，没有半行硬裁，手机没有横向溢出。截图仅含合成记录，保存在忽略的 `.cache/frontend-question-desktop.png`、`.cache/frontend-graph-desktop.png` 和 `.cache/frontend-question-mobile.png`，浏览器验收可重新生成。

Python wheel 包含 API、规则、差异比较和 CLI，与本地源码逐份核对；不含前端静态资源、缓存或密钥。源码部署先在 web 构建，再从仓库根目录运行 `uv run rg serve --open`。单独安装 wheel 时另行构建静态资源，用 `--web-dir` 指定绝对目录。Vite 开发预览不提供生产数据 API；真实复核使用同源本地服务，不关闭生产同源检查。

## 验收边界

研究图最多返回 2000 条记录并标明 partial，不承诺正式全图语义与影响传播；产物内容 diff、运行到研究对象的完整映射、钩子失败账本、远程提取授权界面和 M2/M3 采集正式化尚未实现。手机截图验证布局，不替代全手机操作或真实规模性能验收。

本轮没有读取完整真实会话或发送真实材料，没有新增远程模型调用。Atlas 的正式人工参考与问题仍待人工核对，M1 效果和完整 M0–M4 未达标。用户的前端授权改变开发顺序，不改变这些真实门槛。
