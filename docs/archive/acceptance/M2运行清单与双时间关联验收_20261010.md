## 行为与证据边界

依据 §2/5/8/9/10 和原设计 v1 §5 的可选运行清单，新增离线记录入口。清单原件、候选报告、角色 I/O 与 UUID 回执同事务追加；只记录本地报告，不执行命令、读声明文件、联网或调用模型。运行/版本可先登记明确缺失 ID，后来同项目精确 ID 可在读取视图解析，原观察不回写。尝试及声明快照必须已登记且属于项目。

全部报告及 I/O 保持 candidate/direct_record。输入、脚本、补丁、环境、输出角色的 null 与明确空列表分开，实际 I/O 完整性仍未知。种子按十进制文本保存，参数只作有限 JSON。报告开始/结束和退出码不覆盖原生事实，矛盾独立展示。

五个只读 MCP 仍保留，新增 R: 运行引用。CLI、HTTP 和 MCP 共用双时间读取：原生状态从当前截止内不可变观察重算，观察分页不决定状态；清单与原件各自核对截止。版本和尝试对象可反查报告关联，匹配条件先于分页。清单按 limit/offset，I/O 每份按 io_offset 100 项续读，manifest_id 限定一份；新增原生运行、观察、清单改变 revision。受既有鉴权/Host/同源保护的 HTTP 读取冲突返回 409。
