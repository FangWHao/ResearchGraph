# 物理文件版本与后台完整摘要验收

本轮落实执行规格 §2、§8.2/8.3 及原设计 v1 §5 的内容身份规则。正式 Atlas 参考、实际客户端钩子和完整 M0–M4 验收继续保留；此记录只覆盖当前代码与合成材料。

## 来源与完整性

| 来源 | 身份依据 | 保存内容 | 允许的结论 |
|---|---|---|---|
| shadow_snapshot | 原 Git blob 的 git-sha1，另保存完整内容对象 SHA256、模式、实际影子提交与快照编号 | 原始普通文件字节或链接目标文字 | 证明快照曾保存这些字节；链接不跟随，不能证明运行实际使用 |
| current_file | 后台完整顺序读取 SHA256、字节数、前后签名核对及实际读取窗口 | 摘要与元数据，不复制大文件正文 | 证明读取窗口中的当前普通文件；发现快照只是线索，snapshot_id 为空 |
| agent_edit | 工具直接报告文本与可核对补丁，sha256:tool-utf8 | 既有候选 UTF8 文本或补丁 | 不能等同物理文件编码、BOM、字节或旧运行输入 |

原设计把实际 run manifest 列为可选后续记录，并说明任意 Bash 不会天然提供完整 I/O。本轮没有按时间接近、当前文件或最近快照补造 run_io。

大文件从已保存快照的 large_file 遗漏清单发现，不遍历未登记目录。采用一 MiB 分块顺序读到 EOF，大小和 mtime 不是摘要。缓存键含根目录、路径、设备、inode、模式、大小、mtime、ctime；它们仅提示变化，不防御恶意或不可靠文件系统伪造。缓存复用保留原实际完整读取窗口及 cached_from，与本次观察入库时间分开。

## 队列与故障

数据库版本 13 新增发现结论、发现轮转尝试、文件任务、只追加任务历史、版本观察及完整摘要缓存。任务输入不可改；物理版本、观察和历史不可更新或删除。强杀后的接管必须先取得实际系统锁，提交再核对任务 owner，旧执行器不能发布。

慢读取不持 SQLite 写事务，读前及提交前核对根目录登记。根目录绝对路径的每一级、文件父目录和文件均通过 nofollow 句柄读取；祖先变成外部链接时在读正文前拒绝。前后文件签名、路径、长度或目录变化，结果作废并等待五秒；文件丢失、非普通文件和缺失快照对象留下失败状态，可显式重试。发现阶段遇到忙碌或读取故障留下轮转尝试，避免前二十项挡住后续快照。

scan --watch 与 extract --watch 在出现快照记录后启动固定隔离解释器的本机子进程；参数数组、shell=False，不执行会话命令、不联网或调用模型。父进程通过实际进程句柄和管道管理子进程，正常关闭或父管道 EOF 后退出；不使用 PID 文件或超时猜存活。单次 scan 不等待慢摘要，hash-files 可以单独批处理或持续运行。钩子仍只写 spool/拍快照，未安装系统常驻服务。

## 接口与回归

versions CLI 和 /api/versions 使用只读 Store、参数绑定及精确路径过滤。每页 1–200，偏移有限；每个版本最多三条最近观察，返回观察总量和不完整标记。不会读取当前文件正文、旧原件或升级数据库。HTTP 保持 127.0.0.1、访问令牌、Host/同源保护，健康统计按项目分别计数；running 只是账本状态。

新增 21 个固定案例涵盖保存字节/Git 原摘要/模式/链接、原目录消失、备份恢复、大文件尾部与全文摘要、没有正文副本、发现线索不符、缓存原读取窗口、相同大小和 mtime 下 ctime 变化、正文/路径/父目录变化作废、根目录祖先替换提前拒绝、读期间并发写库、外部链接不跟随、故障显式重试、分页及项目隔离、参数字面量、只追加与旧 owner 拒绝、持锁不接管、实际 SIGKILL 恢复、watch 子进程关闭、实际父进程强杀后子管道退出、版本 12 迁移故障原子回滚、快照缺失不取当前文件修复、发现失败公平轮转及观察历史上限。

专项输出：uv run pytest tests/golden/test_artifacts.py -q → 21 passed in 8.88s；ruff → All checks passed!；pyright → 0 errors, 0 warnings, 0 informations。早期五个失败是测试对 Store 上下文及合成静态目录的错误假设，修正测试环境后通过；随后新增祖先目录防护与案例，早期 583/536 全量结果不替代最终源码的验收。

## 安装包实运行

最终 wheel 有 103 个文件、98 个源码资源，逐字节缺失/差异为零，实际密钥匹配与私有文件为零。独立环境重装后，从仓库外由隔离解释器启动真实 CLI scan --watch，模块确实来自 site-packages。

合成库先保存一个小文件与一个大文件，随后新增同内容快照，再修改大文件尾部保存第三个快照。后台完成六项任务；小文件版本一、大文件完整 SHA256 版本二、缓存复用一。复用时实际读取窗口不变；大文件正文未复制、没有绑定旧快照，没有模型调用或推定的 run_io。只读分页返回三条总版本，备份后在安装环境只读恢复成功，watch SIGINT 退出码为 0。

安装包实测与本地 TCP/模拟模型无关，本轮未请求真实模型、未读取完整私人会话或外发 Atlas 原文。真实规模吞吐、Windows 原生路径、实际客户端整条钩子、完整运行输入输出映射及研究效果均尚未验收。前端的合成来源与分页验收另行记录。

物理版本目前由 versions CLI/HTTP 查看；它们没有原工具事件 evidence_event_id，现有 MCP 的版本原文入口不会补猜其双时间引用。物理版本与研究对象、运行及 MCP 历史的完整语义关联继续后续落实。
