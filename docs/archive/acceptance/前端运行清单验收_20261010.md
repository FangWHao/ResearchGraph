## 展示与保留边界

原文证据内的每条原生运行现在附有候选运行清单。原生请求、启动、结束和退出码继续单独显示；显式报告保持“直接记录、待复核”，不会确认研究尝试、文件版本或成功运行。未知原生状态和仅请求状态不会被报告退出码 0 提升为已结束。

清单展示明确的输入、脚本、补丁、环境、输出版本 ID，以及参数、十进制种子、范围、尝试、声明快照和发生/入库时间。角色的 `null`、明确空列表和有版本 ID 的列表分别展示。版本仅在项目、报告 ID、解析 ID 均一致且返回可见版本时展示；工具报告文本与物理文件字节分开说明。未知或当前不可见版本不补造内容、路径或关联。参数、路径与原文均由 React 作为文本显示。

退出码冲突保留原生值和报告值；错误冲突标记、分页完整性矛盾、异常版本身份或元数据、快照异步竞争均保留中文诊断。清单分页读全仍然显示“实际 I/O 完整性未知”，不等同完整复现或实际使用证明。旧接口缺清单字段按未知显示；有效的空清单仅说明当前未登记显式清单。

初始原文接口最多返回 20 份清单、每份 100 项版本关联。点击续读时先重读第一页建立修订号，再固定该修订累计清单页或单份清单的独立 I/O 页。409 保留此前列表并停止混页，主动刷新后仍需再次点击续读；401 使用已有鉴权入口。迟到响应按运行、项目、原文位置和当前请求核验，不进入新的证据面板。

无原生运行的显式报告仍可经回执原文、CLI、MCP 和 API 查询，本轮证据页没有独立报告浏览入口，也不会伪造 `L1Run`。这个边界经父任务确认，留待后续统一报告浏览。

合成项目包含原生退出 0、未知退出与仅请求三种运行。退出 0 运行登记 21 份报告；富清单明确报告 98 个输入版本、脚本/补丁/环境/输出各 1 个，合计 102 项关联。首次真实 HTTP 返回 20 份清单及 100 项关联，续页读取最后 1 份清单及最后 2 项关联。富清单报告退出 2，与原生退出 0 冲突；大种子 `9007199254740993123456789` 原样保留。合成快照和文件字节仅用于展示与关联验收，不代表运行实际使用证明。

新增 8 个语义单测、6 个浏览器用例，保留原 57 单测及 54 浏览器用例。真实本机 HTTP 检查覆盖候选状态、五类版本、原文跳转、只读不写图、修订固定的两种续页、未知运行不升级、角色未知与空列表、真实 409/401、小屏键盘滚动及原生状态保留。延迟用例取真实后端响应后仅延迟交付，验证旧页不会进入另一个原文或项目。旧接口缺字段、绑定歧义、身份/元数据异常和错误完整性由响应修改合成，明确不是后端实际返回这些矛盾字段。参数中的 `<script>` 和命令替换文字没有执行；元素检查没有生成脚本或图片节点。

## 验收命令与实际输出

所有前端命令在 `web/` 执行，使用仓库提供的 Node、pnpm 与浏览器运行库：

```bash
PATH=$PWD/../.tools/node-current/bin:$PWD/../.tools/bin:$PATH pnpm test
PATH=$PWD/../.tools/node-current/bin:$PWD/../.tools/bin:$PATH pnpm build
PATH=$PWD/../.tools/node-current/bin:$PWD/../.tools/bin:$PATH LD_LIBRARY_PATH=$PWD/../.tools/browser-libs/usr/lib/x86_64-linux-gnu pnpm test:browser
```

最终单测输出：

```text
Test Files  8 passed (8)
     Tests  65 passed (65)
  Duration  651ms
```

最终构建输出：

```text
$ tsc --noEmit && vite build
✓ 208 modules transformed.
✓ built in 1.06s
```

最终浏览器输出：

```text
Running 60 tests using 1 worker
60 passed (41.6s)
```

专项复验为 `6 passed (9.9s)`；完整首轮为 `60 passed (41.6s)`。补充顶部截图与异常版本元数据诊断后，最终完整回归再次 `60 passed (41.6s)`，进程退出码 0。

从仓库根执行 `.tools/bin/uv run ruff check tests/frontend_server.py`，输出 `All checks passed!`；`git diff --check` 无输出、退出码 0。

过程中的失败和修复：初次构建发现未使用的导入，以及浏览器辅助函数没有处理请求事件编号可空的类型，已删除无用导入并在辅助函数核验有效编号。浏览器专项首轮 `5 passed / 1 failed (12.2s)`，唯一失败是小屏键盘按键后过早读取滚动位置；改为等待实际滚动后，专项全部通过。没有放松报告关联、版本身份或完整性断言。
