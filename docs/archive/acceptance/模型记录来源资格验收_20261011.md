# 模型记录来源资格验收

## 行为与数据边界

旧模型记录即使经过人工确认，来源仍可能来自漏标的注入工具或不可核对的保存对象。现在来源资格与审核分别保存：原候选、人工确认、发生时间及L0均保留，来源未通过时不进入模型上下文或自动采用／证据状态。独立人工记录及人工更正保持既有确认合同。

迁移26只新增只追加诊断及必要的修订失效，不读取原件或伪造旧检查。新提取入库时核对全部引用；后台派生按持久游标轮转旧记录，并在各自批次重核已通过及不可用来源。资格输入摘要包含当前策略、断言及引用元数据，变化后旧缓存不复用。诊断不复制正文或模型标签。

查询、研究图、审核详情和MCP只读取匹配诊断。工作集复用已核对且元数据匹配的来源，以保留增量不重读旧历史的合同；无匹配诊断时补查，不可用时重试。跨会话链接在计数前实查两侧卡片的全部引用，仍只发送第一侧有限原文。概览不打开原件，只采用匹配当前策略的结构化记录；上下文以数量说明省略的来源缺口，不发送其原标签。

较新的已确认记录来源待核对或不可用时，采用／证据分别保持未知／未评估，不能回退显示旧确定状态；明确排除的注入记录不决定该轴。发生时间未知及同刻冲突沿共用计算保留。历史诊断按原引用和关联调用的双截止投影，晚到注入调用不能改变更早截止点的来源判断。前端分别显示审核徽章、来源提示与科学状态，保留原历史及原文入口。

## 固定案例与实际故障

新增25项公开合成固定案例，覆盖旧原生注入、人工确认保留、只读查询、混合合格／排除引用、链接第二侧卡片、诊断只追加／恢复／幂等、后台公平轮转、只读评估不持久化、迁移回滚、备份和管理范围清除、跨阶段缓存失效、双截止及当前状态不误回退。测试计数器只用于拦截泄漏，不作为生产token估算。

最初三项红灯为 `3 failed in 2.85s`。首轮关联暴露局部变量与诊断函数重名，以及概览误打开原件；已分别修正。随后旧处理版本测试暴露字典覆盖和模拟旧调用没有关闭新增门控，补齐真实旧行为模拟。新增轮转及流水线测试的初始游标／概览数量假设也经真实SQL队列纠正，保留原失败日志。

## 实际验收边界

来源未发现排除原因不证明模型结论语义有效；匹配缓存不保证物理原件此刻可读，后台重核或下一次实际引用可以发现不可用。模型输出仍只写候选，来源检查不自动确认科学结论。混合用户正文全部路径及真实旧库规模仍需核验，本批不等于全部自引用消除。
