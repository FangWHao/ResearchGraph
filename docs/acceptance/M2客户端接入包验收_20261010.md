# M2 客户端接入包验收

日期：2026-10-10。范围：§2、§8.1、§10、§11、§14；仅合成项目。当前交付是 question/decide/context 的客户端包装，不宣称整个 M2 或 M0–M4 已验收。

## 交付行为

`rg client-pack` 以只读 Store 生成 19 个文件，输出必须是新目录；已有目录或未知项目拒绝，失败清理本次新输出。包内有两套技能、两种 MCP 配置、中文安装说明及文件摘要，数据库逻辑不变。生成不修改个人配置、不安装钩子、不调用模型；用户按说明合并到登记项目的原生目录，保留已有技能与其他配置。

Codex 使用 `.agents/skills`、`.codex/config.toml`；Claude 使用 `.claude/skills`、`.mcp.json`。每套包含 research-context、research-question、research-decide。格式依据 [Codex 技能](https://learn.chatgpt.com/docs/build-skills)、[Codex MCP](https://learn.chatgpt.com/docs/extend/mcp?surface=cli)、[Claude 技能](https://code.claude.com/docs/en/skills)、[Claude MCP](https://code.claude.com/docs/en/mcp)。客户端自身的工作区信任与首次 MCP 许可仍由客户端处理。

上下文允许自动选用；明确范围时直接用 MCP 的完整 scope。人工记录技能只接受用户明确调用，分别配置 Codex 的 allow_implicit_invocation=false 和 Claude 的 disable-model-invocation=true。用户问题、对象、动作和理由作为 JSON 数据处理，不以普通开发请求或旧日志授权人工记录。MCP 五工具保持只读；note/propose_note 类型待定。

包装脚本以参数数组调用固定环境的 ResearchGraph CLI；不经过 shell，不把 `$ARGUMENTS` 插入动态执行块。固定项目和 human:本机用户，入口拒绝项目、actor、未知及重复字段、非对象、超长或缺失 request_id 的 JSON。现有原话证据、完整范围、双时间、版本冲突、跨操作 UUID 幂等及歧义候选合同保留。技能调用约定依赖客户端遵守，不是操作系统身份认证。

生成包含本机数据和 Python 绝对路径；Python 环境链接保留，-I 隔离工作区模块遮蔽。包不包含数据库原文、凭据、项目名称或模型配置，移动环境后须重新生成；本机路径也不宜直接公开。临时请求用后删除，包不自动保管请求副本。

## 验收边界与下一步

本轮验证生成格式、真实 CLI 包装、官方 MCP SDK 和安装后行为，没有请求 Codex/Claude 提供方的真实模型，也未更改个人客户端设置。真实会话触发行为、客户端整条钩子 p95 和研究效果仍需验收。

日常采集/提取与只读查询不要求逐条人工审核；人工技能用于用户主动补记或纠错。后续继续自动关联串联、完整运行 I/O、后台大文件摘要、全图语义、export 和完整隐私清除。note/propose_note 的表示待用户明确；Atlas 正式参考和真实 M1–M4 门槛保留，整个开发目标未标完成。
