# 解析器健康界面验收

日期：2026-10-10。基线：`fdcbad5b58dbbdbec8638e80dbd2f1d21b3af057`。本轮仅负责前端和独立合成浏览器服务；后端、全局进度与发布由父任务记录。开始前保存并逐字核对 HealthView 恢复副本，包为 `.cache/frontend-parser-health-before-fdcbad5.tar.gz`，SHA256 为 `d8fce47ae42ae3697c26d5b7bfd290b9ac153ea0037888e5e4ac92775d564e8d`。

## 行为与边界

采集健康页增加独立的解析器类型／工具版本账本。每页二十个类型分组；续页同时固定首次响应的观测快照与归属摘要，并核对所有统计。分页失败时保留原成功页，明确诊断并要求主动重新读取，不把不同归属、偏移或统计的响应拼成完整账本。面板独立于原健康统计的加载与分页；项目、刷新周期和请求身份变化后，旧响应不能覆盖新项目或触发旧鉴权错误。

物理记录包括各来源文件的副本，不能当作去重后的研究事件数。一条记录可包含多次同类型内容块或多个类型，各组记录数、出现次数、故障标记和总记录数不能相加。非法工具版本也属于版本未知，两项分别显示且说明重叠。已识别仅表示解析器识别／读取类型，不代表提取覆盖完整或科学确认。旧记录未观测、版本未知、非法声明、坏 JSON、结构异常和解析器故障都保留；旧服务统计缺失不补零。

类型卡显示工具与解析器版本、声明或同文件上下文依据、类别、出现次数、物理记录数、来源文件数与入库时间。首次和最近原文分别定位原事件，页面用 React 文本显示原始内容，不执行其中 HTML 或命令。本轮只读元数据和原文，不调用模型、不写入账本、不读取真实会话或个人配置。

## 合成资料与验证方法

独立服务 `tests/parser_health_browser.py` 监听 `127.0.0.1:9796`，只在临时目录构造两个项目并调用真实 `scan_file` 和生产 HTTP。先在迁移版本十八导入一条旧记录，再恢复版本十九并重新打开数据库升级；不删除观测事实，也不补造旧账本。新样例覆盖 Claude 顶层工具版本、Codex 会话工具版本、同文件继承、未知／非法声明、多块未知类型、坏 JSON、解析器异常与二十项以上分页。业务字段 `version` 不冒充工具版本。

早期种子烟测脚本误用了不存在的 Store 查询方法，随后改为实际 `rg.query.parsers.query`；此为验收脚本错误，未修改产品接口。该次烟测主项目为四十四条物理记录、四十三条已观测、一条旧记录未观测和六十一个类型分组。重复未知块为两次出现、一条记录。烟测发生在后端补齐末事件指针之前，不作为最终首末指针证明；最终浏览器服务重新创建临时库，按实际 API 核对首末事件不同及两次原文摘要。

四项浏览器专项保留以下区分：

- 真实生产 API 完整翻页，与每页界面逐项一致；首末原文与引用 SHA256 一致，HTML 为字面文本；读取前后图修订与内容一致且无写请求。
- 真实生产接口拒绝缺少续页身份的四百错误；通过修改请求归属摘要取得真实四〇九响应，界面保留旧页并要求主动重新读取第一页；错误令牌取得真实四〇一，再按既有登录入口恢复。该测试没有实际移动会话归属。
- 最小旧库不可用响应、旧接口四〇四及错误响应元数据是明确的浏览器模拟，用于检查缺字段不补零、格式错误不替换成功页。
- 三百九十宽直接切换合成项目，延迟已取得的真实二百或四〇一响应，并在测试中移除旧请求的 AbortSignal，以证明迟到回包仍被身份检查隔离；这是响应调度模拟，数据与鉴权结果来自真实 API。
