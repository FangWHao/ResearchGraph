## 行为与证据边界

`version-diff BEFORE_VERSION_ID AFTER_VERSION_ID --project PROJECT_ID` 和 `GET /api/version-diff` 共用只读查询。两个明确版本必须属于同项目、同登记根目录与路径；顺序由调用者决定。发生截止和获知截止约束版本与捕获观察，修订检查拒绝列表读取后已变化的比较；较晚的模式矛盾不进入较早视图。

只接受已复制正文的影子快照，核对捕获提交、观察模式、表示、算法与完整复制标记。逐级无链接打开对象库，限量解压，核对完整长度、SHA256、Git blob 摘要及读取期间文件身份；返回实际选用的可见捕获观察。两侧通过内容验证后才说明字节相同或不同。权限变化独立计算；缺捕获证明时模式变化为未知，不把当前哈希或工具报告冒充保存内容。

UTF-8 文本按 LF 分行，保留 CRLF、U+2028 正文及缺末尾换行标记。两侧原字节合计最多64000字节，每侧最多2000行，完整统一差异最多64000 UTF-8字节。二进制、无效编码、来源不支持、对象缺失或损坏、表示转换及超限均返回明确原因，不返回部分正文。链接只比较目标文字，不跟随目标。

查询不打开研究工作区、不运行 Git、不调模型、不写数据库或缓存。候选状态不变，不证明运行实际使用或研究结论成立。版本页面的当前登记列表与比较双截止分开；前端交互、迟到响应及真实 HTTP 验收见[前端验收记录](前端物理版本差异验收_20261010.md)。
