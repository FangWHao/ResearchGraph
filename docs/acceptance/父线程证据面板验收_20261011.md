# 父线程证据面板前端验收

本轮在 2026 年 10 月 11 日完成，起始版本为 `aa92e9c31cc25b1d98a0d035cafa3c92ca561bbd`。只扩充原文证据中的 Codex 父线程依据；后端、主进度、设计决定和其它健康组件由父任务维护。

## 显示与历史边界

父线程信息随已有原文接口的同一只读快照返回，本组件不另发请求。会话头的源声明与当前本地解析的父线程关联分开显示。未观测、未声明、无效、冲突、找不到父头、身份不唯一、循环与跨项目均不被解释为根线程；已关联也不代表研究内容的使用、采用或科学确认。Claude 的不适用状态不显示此区。

面板保留后端核对全部头观测后的关联结论。超过二十条时只展示最近二十条，并明确历史省略；不从当前显示的声明重新挑选父线程。跨项目仍可查看本会话头中原有的父 UUID，但不公开解析父会话编号或父原文引用。响应身份、枚举、数量或引用异常时显示关系暂不可判断，不生成导航。

父头和头声明导航只传原文事件编号。源文件中 JSON 行的字节位置不被当作原文对象内引用窗口。正文、诊断和 UUID 都以 React 文本展示，不执行 HTML 或命令。沿用原证据面板的请求取消与错误处理逻辑。

## 合成资料与检查方式

独立服务 `tests/session_parent_browser.py` 使用临时目录、真实 `scan_file`、生产迁移和 API，在 `127.0.0.1:9798` 提供两个合成项目。旧库先在版本二十保存头记录，再升级但不重新扫描，以保留未观测状态。新库包含两处一致声明、真实迟到父头、二十一条头中的旧冲突、跨项目、无效、循环和重复原生身份。服务和资料不涉及真实会话、临床资料或模型调用。

原文字节检查另请求明确的全文窗口，核对 UTF-8 长度和 SHA256；未指定引用窗口的原文响应摘要保持 `null`。导航晚回包测试获取真实本地 API 的成功或鉴权失败响应，再由测试路由延迟交付。为验证取消后的迟到交付，测试传输有意忽略 AbortSignal；生产组件仍保留取消及身份检查。坏会话身份响应只在测试路由中注入，不能称为后端真实数据。
