## 实现行为

决定时间线提供“记录人工决定”。对象原话、动作、理由和范围均由用户主动输入，动作没有默认值。对象原话和理由不裁剪空白、不改写换行。空范围发送 `null`；已知范围按完整字典发送。原话最多 4000、理由最多 16000、整条请求最多 65536 个 UTF-8 字节，范围复用现有的 32 项、键 100 字符、值 500 字符校验。

唯一目标产生人工确认的决定事件，但目标对象的模型候选仍保持候选。同名或没有目标时保留 `target=null`、原动作和理由，在复核队列、详情和时间线均提供“确定对象”。载体编号不作为真实决定对象，也不生成采用节点。普通确认、修改和包含这类记录的整组确认明确禁止；整组确认的分页读取发现未确定对象时，在提交整组请求前中止，保留逐条复核入口。驳回仍可使用，已驳回或已替换记录不能继续确定对象。

对象列表调用全项目目标接口，每页最多 200 项，按字面搜索，并按原完整范围筛选。不凭图中已加载的部分记录判断唯一性，列表和单一搜索结果均不自动选中。确定对象只提交目标 ID、记录者、独立请求编号和版本；原动作、理由、范围与发生时间保持原样，新记录追加替代关系，旧原文和证据保留。已解决的原记录明确关联确定对象的替代版。

`null`、空字典，或范围值为 `unknown`、`未知`、`未确定`、`不详`、`unspecified`、`?` 时，采用状态为范围未知。人工确认事件仍可在时间线查看；选择对象不会补造范围，缺范围事件不决定当前采用。

创建草稿按项目、选择草稿按项目和原记录分别保存在页面内存。同一内容的网络失败重试复用原请求编号；修改原话、动作、理由、范围、目标、记录者或项目会形成新意图。双击和重复提交事件不会产生并行写入。409 后保留草稿，读取最新版本后仍须人工再次提交。401 交由统一鉴权，恢复后保留输入和选择，不自动写入。旧回包核对项目、原记录、请求编号、当前草稿内容与鉴权代际；旧成功可以刷新数据，但不会清掉新的草稿或打开另一记录，旧错误不会让另一项目的新表单登出。

## 真实接口覆盖与显示边界

真实本地 HTTP 使用“验收新增决定项目”和“验收新增决定项目二”，初始对象分别为 209 和 1 项。209 项包含一个唯一方案、两个同范围同名方案、一个其他范围方案和 205 个分页对象。范围为 `data=synthetic_decide_v1`、`step=手工决定验收`，其他范围使用 `synthetic_decide_v2`。

浏览器实际检查：唯一决定确认后目标仍为模型候选；原理由的空白、换行、引号和反斜杠保持；原文引用窗口按原始 JSON 字节实算 SHA256；保存后图和时间线刷新；同名候选的确认、修改和整组确认入口禁用，后端普通确认返回 400；主动选择追加替代版并保留旧记录、原时间和证据；目标分页读取 200 项及末页 9 项，单一搜索结果仍不选中；空范围确定对象后仍为 `null`；两个项目的实际成功写入归属正确。

失败路径通过实际接口制造非法动作 400、另一窗口写入造成 409，以及无效合成令牌造成 401。保存已成功但浏览器丢回包时，创建和选择均用原请求编号重试找回同一记录，无重复追加。创建旧成功延迟时，切换项目后输入的新草稿不丢；旧选择成功延迟时，另一原记录的新选择保持且成功写入正确目标；旧实际 401 延迟时，另一项目的新草稿和登录状态保持。已驳回决定刷新后不再允许选择对象。

名称截断提示的浏览器覆盖单独使用响应覆盖：先读取真实目标 HTTP 回包，再将一项名称改为合成预览并设 `label_truncated=true`、`label_total_bytes=12000`。此项只验证前端不把预览视为完整名称、没有默认选择；该 12000 字节数不代表浏览器种子中的真实名称长度。其他目标身份、分页、选择和原文检查均使用真实接口。前端验收未声称实测后端超长名称存储边界。

## 失败到修复

初次构建在测试样本类型不完整时失败；补齐完整记录字段后通过，未放宽业务类型。第一次新增浏览器运行 `5 passed / 4 failed`，耗时约 1.3 分钟。实际手机缺陷是时间线的范围下拉撑开页面，已给筛选标签与下拉增加可收缩宽度，详情按钮允许换行。另三项为测试定位问题：误把第一段动作引用当对象引用、未分页到新候选、试图穿过弹窗点击背景刷新；分别改为按原文位置定位、读取队列真实分页、在弹窗内读取最新版本。

第二次 11 项运行 `10 passed / 1 failed (43.1s)`，余下失败是队列分页测试在上一页尚未卸载时再次点击，误走到末页。改为等待真实分页 HTTP 回包，并核对新页首条记录编号。该项复验 `1 passed (5.6s)`。随后最终全部 30 项通过；增补另一项目实际成功写入后，再次完整运行仍为 `30 passed (23.8s)`。
