# M1 链接调度与输入遮盖验收

日期：2026-10-09。范围：§2、§7.7–§7.10。当前为后端试验版，完整 M0–M4 和 Atlas 真实效果门槛仍未完成。

## 本轮行为

- 链接进度写入数据库版本 3。`--limit` 只计本次新尝试或显式重试，完成缓存不占用下一页额度，也不再读取原文、计数或生成。失败对默认跳过，后续对继续处理；`--retry-failed` 使用原人工任务。
- 每日额度不足暂停当前任务；链接计数或提供方不可用同样保留 pending。提取暂停保留覆盖缺口与排队通知，恢复后完成通知并清除旧错误。
- 同项目链接使用非阻塞系统进程锁，期间不占用 SQLite 写事务。进程被杀后可重新取锁，锁文件存在不等于进程存活。
- 模型、提示、schema 和有效输出上限参与处理身份；对象版本和审核状态变化进入新的候选对身份。合法输出仍为 candidate；已有关系提交后的中断恢复不会重复生成候选。
- 遮盖只在规定的程序元数据路径保留生成标识符；自由文本、范围、原文中出现的同名键仍照常遮盖。无关系输出的端点必须为 JSON null。
