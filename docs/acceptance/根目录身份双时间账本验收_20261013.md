# 根目录身份双时间账本验收（2026-10-13）

本轮给根目录登记增加不可变身份观察。后来的 Git 身份不再冒充过去已经知道的信息；版本、运行、编辑和快照的双时间读取提供独立登记证明。界面入口不变，已有版本差异提示区能够显示登记时间未知的缺口。

## 实现与范围

- 迁移37增加 `source_root_observations`，记录原声明、登记／元数据变化／旧库基线、发生时间和入库时间。登记和变更由数据库触发器同事务追加，失败整体回滚；稳定重复不新增观察。观察不可更新或删除，整项目隐私清除为例外。新增观察推进图修订，已有登记入口不重复推进。
- 升级只复制旧库已经保存的声明，不探测工作区或 Git。旧登记基线的发生时间为空，入库时间是实际升级时间；升级之前的历史视图显示未知，不从项目创建时间推算登记时间。
- `project roots` 增加 `--occurred-until`、`--known-until`，沿同一读取快照和修订分页；时间需带时区，UTC偏移和微秒截止按真实时刻比较。当前根清单仍按SQL分页，历史清单核对可见声明及明确科研归属，迁移后借用的物理根保留原登记项目声明。
- 文件版本、原生运行、L1编辑及快照共用读取者的根身份缓存；历史读取只取当时已经保存的观察，不打开对象正文或当前工作区、不调用 Git、不写回记录。旧物理事实与科研状态不改写。登记未知与旧库发生时间未知分别提示，不把路径身份视作实际I/O证明。
- 备份保留账本。原项目清除时仍被目标科研记录使用的物理根和全部登记观察一起保留；最后一个引用清除后，在同一隐私事务回收观察和根，不留下只因账本自引用而永久保留的来源身份。
