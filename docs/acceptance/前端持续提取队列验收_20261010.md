## 状态解释与兼容

队列按接口返回的范围显示“当前项目”“全库 · 所有项目”或“范围未知”，总数与各状态计数直接读取完整范围统计，不由当前页任务求和。

| 账本值 | 界面显示 |
| --- | --- |
| `queued` | 等待处理 |
| `running` | 处理中（账本） |
| `done` | 本次任务完成 |
| `partial` | 部分结果 · 有缺口 |
| `paused` | 等待每日额度 |
| `blocked` | 受阻 |
| `cancelled` | 已取消 |

页面明确说明：处理中账本不证明进程仍活着；本次任务完成不代表会话全部原文已覆盖，也不代表候选事实已确认。每日额度不足时等待下一个 UTC 日，下次尝试时间不作为已执行的证明。部分结果仍保留缺口，默认不反复重发；原文仍可从既有覆盖缺口区查看。

任务展示会话、项目 ID、模型、原文事件边界、尝试次数、创建和更新时间、下次尝试、等待原因和错误记录。额度与远程调用许可原因显示中文，安全错误类保持原值。明确的 `null` 下次尝试显示“未安排”；缺字段显示时间未知。不存在的错误字段显示未知，明确 `null` 显示无错误记录。

旧后端没有队列对象时，全部计数和范围显示未知；不能据此宣称没有任务。缺少某个计数时不补零，实际零值保持为零。任务字段缺失、陌生状态和分页缺失均有未知展示；不能通过当前页推断完成或猜测下一页。任务列表支持键盘纵向滚动，手机卡片和分页按钮可换行。
