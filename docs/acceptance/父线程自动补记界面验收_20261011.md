# Codex 父线程自动补记界面验收

本轮以 `a28c915515d1b86aec592cca968aec8651074088` 为前端基线，只更新父线程证据面板、类型、语义测试和独立合成浏览器服务。后端实现及全局进度由父任务维护。本轮未读取完整真实会话、调用模型或操作真实项目；所有测试原件均为临时合成 JSONL。

## 界面语义

`metadata_incomplete` 可以带零条或多条已存头观测。界面分别显示本会话已存来源补记完整度和全管理库 Codex 已存身份核对完整度，保留源声明，不把积压、零观测、未声明或旧接口缺字段解释成根线程。已观察到的无效或冲突不因积压而消失，完整度也不代表科学确认、所有原始日志已收齐或完整祖先史。

父导航要求两个覆盖字段都严格为 `true`，且接口确认为同项目 `linked`。旧响应字段缺失或 `null` 显示未知；任一字段为 `false` 显示未齐。即使旧接口报告 `linked`，完整度尚未成立时也不显示父会话编号或导航，只保留可以核对的头声明。源声明和父头导航都只传事件 ID，来源文件字节位置不当作原文对象窗口。

补记由正常后台扫描推进，不增加人工确认或模型步骤。证据面板沿用一次证据查询的只读快照；本轮没有改变外层取消、响应身份或鉴权逻辑。跨项目只保留子头原话，完整关联、歧义和冲突都不改变研究采用、证据或审核状态。

## 合成场景与证据

新增独立服务 `tests/parent_backfill_browser.py`，只监听本机 `9800`，使用独立临时数据目录和合成令牌。准备时建立迁移 20 的旧库，实际 `scan_file` 摄取七个自身合成来源，关闭库后删除这些原日志，再升级至迁移 23。三个长来源各 260 条物理记录，短来源含真实会话头和正文。浏览器通过仅测试的空对象控制器执行生产 `watch.cycle`，不直接伪造接口状态或修改不可变观测。

首批与次批核对数量从该合成库的实际物理记录数计算。用例检查积压仍保留已观察声明、自身已齐但全库身份未齐时不发布唯一父、第二批补齐后的关联、末尾父声明冲突，以及另一项目迟到重复身份造成的歧义。原文证据通过明确全文字节窗口核对 UTF-8 长度及 SHA256，补记前后原 L0 摘要与入库时间不变；既有头观测的补记时间也不被第二批改写。

原 `9798` 父线程服务保留真实迁移 20 头记录。原四个浏览器场景继续检查两处声明、原文 HTML 不执行、父头迟到、最近 20 条不能抹去更早冲突、跨项目隐藏引用、错误身份以及取消后迟到的真实 200／401。旧库升级先实际检查积压，再运行真实扫描循环补齐；补齐后的未声明头不被称为根线程。

兼容用例只对真实本地 API 响应的覆盖字段进行受控删除、置空或置假，用来验证旧响应展示；这些兼容响应不冒充后端真实覆盖结果。取消后的迟到响应仍由原有专项验证，受控传输忽略取消信号只用于让浏览器实际收到晚响应，生产取消逻辑未改变。
