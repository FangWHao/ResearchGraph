## 行为与边界

旧前端使用毫秒比较事件，可能把同一毫秒内先后发生的相反事件误报冲突；单条缺时间证据还可能被当成有效支持。当前采用和证据计算改用完整微秒，继续隔离候选、驳回、被替换和其它完整范围。真正同刻的相反记录为冲突，任一有效确认事件发生时间未知为时间未知；未知范围的证据为需复核。时间诊断单独映射中文，六种人工可编辑证据状态不变。

后端声明、查询卡和语义图来源追加 UTC 六位微秒规范字段。复用原 Reader 的带时区 ISO 解析，保留原始发生时间、入库时间和原文。Python 支持的紧凑日期、周日期、逗号小数与秒级偏移通过规范字段跨端传递；无时区、非法日期、缺失或 UTC 换算越界返回 null，越界不再造成查询异常。旧接口没有规范字段时只做严格兼容解析，显式 null 不回退。

入库时间和记录 ID 仅可稳定排列时间线，不选择研究事实。本轮不调用模型，不改写数据库原件，不升级候选、不清除真实项目、不改变源规格或 schema17。完整 §15 与真实 M0–M4 验收继续保留。
