# M1 独立原话规则确认验收

日期：2026-10-09。范围：§2、§5.3、§7.6–§7.7 的独立确认及候选保护。真实提取质量与完整 M0–M4 尚未通过验收。

## 实现与证明范围

候选入库后、事务提交前，程序独立解析 L0 的完整用户正文。明确采用、撤回、拒绝、发现的 refuted，以及声明所有命名输入必需的 all_required 可获得规则确认。模型行仍保存 candidate 和 model actor；确认追加为 rule:explicit-user-v1 的审核记录，原事件、范围、摘要与理由依据可追溯。人工审核入口不接受模型身份。

标签唯一性核对整个项目中相关对象，不能只在预算装入的少量卡片中查重。没有完整范围筛选时，其他范围的同名对象也会阻止标签确认；显式筛选后限定于严格相等的范围。原文里的精确 ID 必须匹配项目、范围和本次工作集；临时对象、unknown 范围不自动确认。被 ID 直接提及的 finding、join 和已关闭对象可以进入工作集，默认检索不扩大这些类别。

明确动作不等于模型解释也正确。理由须逐字来自完整声明或明确因果子句，或为可核实的标准动作描述。条件句、建议、问题、引用别人的话、代词、多个正文块、工具返回和 assistant 不能因模型填写 user/explicit/true 而获得确认。同名、截取部分声明和模型自编理由均保留 candidate。已有人工确认不被新规则覆盖，人工驳回优先。

确认与候选同事务；故障时二者和图版本一起回滚。重复确认不追加动作，原候选保持不变。真实 worker 路径验证下一次工作集能读到确认的采用状态；本会话自身规则动作不使完成缓存失效，重复 process 不再次生成。其他会话或人工审核仍参与缓存版本。

新候选与同一对象、类型和范围的有效人工确认提供逐字段比较。比较函数只查结构化记录，不按相似标签推断身份；人工驳回的旧确认不再作为有效比较。报告和本地 API 展示旧记录 ID、人工来源、范围、发生/入库时间及差异字段，由复核者决定后续动作。

## 限制与真实门槛

规则识别独立声明和限定的语言结构，未识别的自然语言保留人工队列；不是对所有中文/英文的语义判定。发生时间缺失仍显示缺失，规则确认记录的是用户的明确决定或证据判断，不证明科学因果或真实实验表现。固定案例通过不能给出真实错误数、找回率、自动确认比例或复核耗时。

用户已另行授权提前开发前端，改变开发顺序；Atlas 的人工参考与正式问题仍不可由程序补造，M1 实际效果和完整 M0–M4 条件仍未满足。
