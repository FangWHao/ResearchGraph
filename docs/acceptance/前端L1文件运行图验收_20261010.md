## 历史语义与完整性

五个集合 `nodes`、`edges`、`observations`、`evidence`、`unresolved` 全部逐页读取，每页 100 条，不沿用研究图的 2000 条画面上限。第一响应确定修订、发生截止和获知截止，随后所有集合及续页沿用。分页核对项目、双截止、范围、修订、计数、节点类型计数及完整性标志；重复、跳页、计数漂移或格式损坏均显示错误，保留此前图或明确标记的部分结果。

“已读完登记图”只表示读完登记数据，不表示实际运行依赖或输入输出完整。候选清单、工具编辑、物理文件字节与原生执行观察分别展示，候选报告不会覆盖原生退出码。未知 ID 保留诊断，不补造节点。声明输入输出连接清单或编辑记录，不连接到原生运行冒充实际读写。

尝试节点保留全部内容版本及其状态和证据，未按最后一条记录选定当前内容。范围可以不限定、填写完整字典精确筛选、或明确选择未知范围；范围归属依据报告关联，不由路径或快照猜测。空列表与未报告字段分别显示。快照捕获、发现线索、缓存复用原读取窗口及工具报告文字保留区别。

原文只使用 `/api/l1-evidence`，固定该图的修订及双截止，不调用旧证据派生接口。每个 UTF-8 窗口核对项目、事件、连续字节位置和 SHA256 后才加入；续读冲突保留已有窗口并要求主动刷新。命令、参数、路径、版本正文和原始 JSON 均作为 React 文本显示。

项目切换、鉴权改变、阅读条件改变和请求代际改变均隔离旧响应。409 不自动重试或混页；401 使用既有登录恢复入口，保留该项目阅读草稿。停止读取只停止页面等待。

## 失败定位与修复

初验新增测试的集合交叉类型造成 TypeScript 错误，改为明确替换 `items` 类型；未放宽接口结构。首次浏览器 4 通过、2 失败：一项比较了 `innerText` 和文本节点的不同换行，另一项误以为“合成空项目”没有 L1 节点；按同种文本读取方式及真实接口计数修复。“合成空项目”有一个登记尝试，没有借项目名称猜测为空。

物理观察专项初次假定发现快照可见，但接口按根和双截止返回未知。改为保留未知并使用原有合法捕获种子验收，不修改合成原件或放宽时间规则。

桌面/手机实看发现手机画布空白。新增真实节点与画布及屏幕边界相交断言后，确认新布局仍沿用旧单节点视口；仅有节点 DOM 数量无法证明可见。修复受控节点未保存 React Flow 测量变更的问题，并在测量完成、布局更新及画布尺寸改变后重新适配。修复后的手机真实专项 `1 passed (8.7s)`；最终专项继续包含真实可视边界断言。
