# 前端整项目清除验收

日期：2026-10-10。基线：`270b099f822049adc441c200f3dad3ac29f2b118`。本轮只修改前端、独立合成浏览器服务和本验收记录，没有修改后端、源规格、全局进度、决定或主说明，没有提交或推送。

## 行为与边界

新增“项目清除”导航。先选定项目并读取服务端的整项目影响清单，显示数据库行、对象、管理路径、共享对象保留数及归属阻碍。清单不借用当前图的分页、范围或历史截止。无阻碍时必须完整输入项目名称并主动点击执行；有阻碍时不提供执行按钮，不跳过记录。

清除范围是当前数据目录管理的整个项目。外部 Claude / Codex 日志、研究工作区、用户另存或分享的副本保留；不能收回已经外发的资料。原文、索引、缓存、快照等实际删除由后端执行，前端只展示经过身份和格式校验的预览及回执。

每次执行意图使用规范 UUID。网络未送达后的重试保留同一请求编号；新清单使用新意图。防双击；409 不自动重发，需检查状态、重新预览并主动执行。401 使用已有统一登录。切项目、切页面、鉴权和版本变化使旧预览失效；迟到清除成功仍归属于原请求，不会把新选择的项目写入旧请求。

状态和恢复接口独立于普通项目读取。挂起期间普通读取返回 409 时，默认页面仍提供“打开清除恢复”，清除页也可在没有项目列表时恢复已登记的同一个请求。空闲状态不作为某次清除成功的证明，只有匹配的完整完成回执才显示完成。

完成后自动重新载入页面，释放当前页面此前读取的资料。确认区明确说明所有项目未保存草稿会丢失；其他标签仍需另行关闭。重载只临时保留无原文的请求 UUID 和既有访问令牌，按请求编号读取服务端完成回执后删除临时标识。已清项目从重新读取的列表消失，其他已保存项目仍可读取。

## 合成与真实接口的区分

`tests/project_clear_browser.py` 在独立临时目录建立九个虚拟合成项目，监听 `127.0.0.1:9792`，不读取或修改既有 8791 浏览器验收库，不读取真实会话、临床资料或密钥，不调用模型。包含独有原文、跨项目字节相同的共享对象及明确跨项目行依赖。

预览、执行、状态、恢复、鉴权和归属规划均调用生产后端。占用用例在独立服务内临时保持实际 Store 共享占用，使真实独占执行返回 409。中断用例仅在此服务进程的 `_finish` 注入一次异常，位置是数据库已提交、管理文件尚未完成清理；挂起状态、普通读取拒绝及后续恢复仍使用生产逻辑。此用例不是进程强杀测试，也不声称覆盖后端全部清除阶段。

网络未送达通过浏览器中止请求模拟；迟到响应通过保留真实后端响应后延迟交付模拟；401 通过向真实接口传入无效合成令牌取得。没有伪造成功回执、删除清单或恢复数据。合成正文中的 HTML 只作为资料，未执行。

新专项由现有 `pnpm test:browser` 自动发现，单独启动和清理其拥有的 9792 服务，不需修改原浏览器服务或 CI 工作流。检测端口已被占用时直接失败，不终止其他进程。
