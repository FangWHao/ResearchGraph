## 已实现的读取边界

研究图独立读取 `/api/semantic-graph?collection=claims`，每页最多一百条，不再使用其它页面的前两千条简版图。首次响应固定项目、修订及发生／已知双截止；后续全部页、记录详情和原文引用沿用相同条件。范围明确为项目内所有范围，内容版本按对象及完整范围保留。用户可指定带时区的双截止；截止比较保留微秒。

页身份、总数、偏移、连续进度、完整标志或记录结构矛盾，以及重复记录 ID，均拒绝混页。读取失败时保留此前的完整图及其原阅读条件，明确提示错误，禁止以失败或未读完的新请求验证折叠；修订冲突须主动重新读取。项目、页面、阅读条件、修订刷新或授权改变均取消原等待，并隔离迟到响应，没有自动无限重试。

图打开的详情是同条件只读历史，不能在历史抽屉确认、驳回或修改。当前复核流程仍保留。历史原文不加载当前父线程、事件父链、L1 运行或文件版本派生；界面明确说明“未加载”，不当作没有记录。原文、自由文字、HTML 字面量和命令均只作为 React 文本显示。
