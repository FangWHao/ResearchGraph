## 实现范围

- 比较端口分别表示被选输入和仅比较的未选对象，未选对象与相同主题关系不参与过程组语义连通或边界判断。共同输入和证据综合各自保留命名端口。
- 存在 `replacement_ids` 的旧确认退出有效内容、关系、汇合、采用和证据状态计算；原始记录继续保留在历史清单与时间线，不复活为当前事实。
- 研究图保留同对象、同范围的所有有效内容版本。多版本对象默认没有选中内容版本，用户可选择显示；选择不追加审核，也不推定当前内容事实。其他页面的兼容投影没有扩展。
- 过程组逐条保存内部关系与穿越边界的原关系 ID、类型、源对象、目标对象、端口及证据引用。不将多条边合并成笼统依赖。
- 组内保留版本、决定、证据状态、不同范围历史、待复核和已驳回记录。撤回、阴性结果和未处理审核可从保留清单打开详情及原文。
- 折叠仅改变画布，展开使用同一修订的全部成员、内部及边界关系、证据、决定、共同输入和节点位置。关系有环时保留原边；不能证明单入口单出口、连通或原记录完整时拒绝折叠。
- 小屏可以用节点复选列表选择过程成员，仍由同一语义检查决定是否允许折叠。

## 真实接口与模拟边界

1. 真实图接口自动寻找可折叠的两个中间节点。折叠保留 11 条相关历史记录、11 条原证据和 4 条原关系，包含一条仅检索的主题关系、撤回、被否定、候选需复核及另一范围内容。组中逐条核对原关系对象、类型、端点、端口、ID 和证据集合。
2. 组内边界关系打开详情和同一原文窗口，真实证据 API 的窗口内容 SHA256 与 span 引用相同。展开后全部原节点 ID、所有边 ID 和节点位置与折叠前相同，前后图 API 的全部响应保持相同。
3. 真实比较端口区分被选与未选，共同输入多入口拒绝折叠。多有效内容版本起初未选择，主动选择后打开的是指定版本；显示选择不修改库。
4. 隐藏候选和真实缺少同范围端点的独立项目均拒绝折叠。只有 partial 场景模拟真实图响应上的 `partial=true`，用于证明前端不会凭部分画面折叠，没有把它当作真实后端分页案例。
5. 真实 `/api/claims/{id}/edit` 追加内容与决定的人工更正，并对关系和汇合做保持原语义的人工替代复核。旧内容、旧边及旧汇合退出有效集合，当前动作变为暂缓；原撤回仍作为已替代历史保留，旧证据窗口摘要不变。未尝试通过 edit 改不可变关系或汇合指向。
6. 390 小屏通过复选列表实际选择并折叠，保留的撤回、阴性证据、候选审核与范围均可追溯；页面没有横向溢出。

## 失败与修复

- 首轮 4 个专项均在节点选择时超时：复选状态与画布选择回传触发布局重建循环。将选择同步从布局依赖中分离，修复后折叠、边界原文及完整展开定向通过。随后一项用例因此前点击内容版本已选择一个画布节点，再选择两个成员时实际为三个；用例改为在新的选择意图前主动清空选择，未绕开语义校验。
- 首次旧全量为 72 passed / 1 failed (56.7s)。新图种子复用其他测试的物理来源 helper，导致全库来源路径从 8 变为 9；父 agent 改为从头创建明确的虚拟合成来源，没有改写 L0 或放宽健康断言。
- 新增真实更正首次返回 400：合成 payload 缺 `claim_type`、实体 `temp_id` 及决定的明确发言字段。父 agent 补齐新种子的合法结构；前端未补猜不可改字段、未放宽 schema。最终 5 专项均通过。
