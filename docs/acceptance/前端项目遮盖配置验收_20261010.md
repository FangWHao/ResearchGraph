# 前端项目遮盖配置验收

日期：2026-10-10。基线：`aa3569a`。本轮只修改前端及本验收文档，没有提交或推送。后端接口、迁移、模型协议模拟和合成种子由父代理负责。

## 已实现的行为

研究问答和历史导出共用“项目编号遮盖规则”面板。面板明确当前项目，支持每行一个正则，分别展示已保存规则与未保存草稿。各项目草稿仅保留在页面内存，可在 390 像素宽页面内直接切换所属项目。清空后主动保存只移除额外项目规则，内置遮盖继续生效。

规则用于项目的模型计数、生成和历史导出，本地原文不改写。历史导出已有的额外规则仍仅用于当次下载。保存不会关闭已有外发许可，也不声称已收回此前发送的资料。正则原样提交，由服务端使用自身语法校验；前端只检查条目数、字符上限、人工身份及记录版本。

保存成功，或重新读取发现项目策略变化后，该项目的旧问答发送预览和勾选状态失效。此前结果保留并标明使用旧规则；需主动重新查询。导出停止旧页面等待并重新读取版本，不自动下载。停止页面等待不意味着服务端或远程请求已停止。

400 保留规则供修改；409 禁止直接重发，读取最新规则后仍保留草稿，需再次主动保存；401 进入既有登录流程，登录恢复后草稿不丢。回包核对项目、人工身份、页面代次和原样规则意图，迟到成功不能清掉新草稿或写入另一项目的页面状态。读取期间更换人工身份会启动新读取，旧响应不能让页面持续等待。

## 合成资料与证据边界

实际浏览器通过本机 HTTP 接口访问“验收遮盖项目”和“验收遮盖项目二”。种子使用独立虚拟来源，包含固定虚构住院号 `HOSP-246810`、病案号 `CASE-135790`、样本号 `SAMPLE-ABC123`、合成邮箱和字面脚本文字；不读取真实会话、临床资料或密钥，不改变既有物理来源统计。

检索、预览、保存、许可、生成和 ZIP 下载均执行真实本机后端。提供方协议沿用合成 `httpx.MockTransport`，不连接外部模型；因此结果证明接口与界面行为，不证明真实提供方或临床研究效果。并发用例只暂存已完成的真实 HTTP 回包以制造迟到，不替换其内容；401 用错误合成令牌请求真实服务。

验收核对保存前后的断言集合相同、原文引用文字相同，三类临床编号从新发送预览、模型引文和含正文的 ZIP 消失，而本地原文保留。ZIP 包带当前项目策略摘要，下载请求使用保存后的记录版本。字面脚本在本地原文中仍为文字，未执行。
