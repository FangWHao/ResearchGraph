# 运行与编辑记录阶段验收

本任务落实 §2、§5.1–5.3、§6.1–6.4、§8.1–8.3、§9 的一部分。从基线 7e2659b 开始，基线恢复包验证有效。这里的运行、代码和输出全部为合成材料；没有读取真实完整会话，没有调用远程模型，没有安装用户客户端钩子。整个 M0–M4 仍未验收完成。

## 可核对行为

新增 rg/derive，直接读取已复制的 L0。导入新事件和 scan/watch 消费后有界派生，也可用 derive 手工继续。运行观察与编辑记录只追加；工作队列与事实同事务，提交前故障会一起回滚，L0 与日志游标不动。项目未归属、调用缺失和执行器归属不唯一保留等待；失败需显式重试。

运行依赖同会话唯一调用 ID；同命令不同 ID 是两次运行，不同会话相同 ID 不去重。requested、started、exited、unknown 分开保存。无结果不标失败，stdout 的 exit_code 文字不当作退出结果，is_error=false 不补零。重复 ID 或冲突退出码保留原观察并显示未知，轮询句柄不能跨会话或歧义关联。开始时间没有直接记录时为空。

原生 Codex 执行器的退出元数据与 stdout 分开；实现只识别明确结构或正文之前的执行器头。格式核对依据为 [官方执行工具实现](https://github.com/openai/codex/blob/main/codex-rs/core/src/tools/context.rs)。这里没有运行会话中的命令，也不解析 JavaScript 执行器包装来猜嵌套命令。

Claude 编辑报告的原文与补丁严格核对，保存候选前后文本。摘要使用 sha256:tool-utf8；工具报告的 UTF8 表示不是对物理文件字节、编码和 BOM 的验证。Codex Update/Delete 保留补丁、完整版本未知；成功 Add 可保存报告的新增文本，编辑前仍未知，因为新增操作也可能覆盖旧文件。实现依据为 [官方补丁执行与成功摘要](https://raw.githubusercontent.com/openai/codex/main/codex-rs/apply-patch/src/lib.rs)。不会从当前目录、最近提交或快照补造旧文件。

证据 API 提供运行观察、请求/结果原事件、候选版本、补丁与派生状态。每事件最多 20 个运行、每运行 100 个观察、20 个编辑、40 个版本；超过则标记部分清单。差异每份及每事件正文合计最多 64000 UTF8 字节，每份最多 2000 行；超限显示不可用而不静默截断。运行命令最多展示 8000 UTF8 字节，返回完整字节数和预览标记；完整命令留在原文，观察明细仅重复命令摘要。非字符串的历史 cwd 不作为有效目录，也不会中止 L0 摄取。完整文本为候选；仅补丁不能显示成完整版本。备份保存候选文本及补丁对象，原文件删除后恢复仍能展示。

## 前端合成接口

tests/frontend_server.py 用实际导入和派生产生事件 11–24：仅请求、运行中、退出 0、退出 2、退出未知、Claude 完整候选文本、Codex 仅补丁。实际运行状态分别为 requested、started、exited、exited、unknown；完整候选差异为 reported_versions，更新补丁为 patch_only。未知样本的 stdout 含 exit_code:9，仍不补退出码。

首次前端浏览器运行发现工具事件不进入现有正文搜索，三个新增入口案例超时，原八项仍通过。修复在原文检索页增加独立的全库事件编号入口，编号跨项目，读取既有证据 API；正文检索口径没有放宽。前端最终 pnpm test 为 21 passed（734ms），pnpm build 为 186 modules/1.41s，pnpm test:browser 为 13 passed（13.4s）；详细真实接口、边界响应和截图范围见 [前端运行与编辑验收](前端运行与编辑验收_20261009.md)。父任务已核对桌面/小屏完整编辑、仅补丁及命令预览图像；截图不作为实际长命令采集证明，真实字节边界另由后端固定案例核对。
