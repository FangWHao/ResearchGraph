## 行为与阅读边界

文件版本页增加明确选择的比较前、比较后完整版本标识。列表翻页保留两侧选择，同项目同登记根目录和路径才可比较；不会选择最近版本、交换方向或按路径推断研究范围。原列表仍读取当前登记元数据，两个带时区截止仅约束本次比较。留空截止由查询固定；最多六位小数秒，回包以整数微秒核对，等价时区写法兼容，微秒不同不借毫秒精度混用。

来源卡分别展示候选状态、完整版本引用、登记模式、摘要、表示、来源、双时间和保存字节核对结果。可展开本次选用的来源观察，包括观察标识、捕获及发现线索快照、影子提交、时间与完整读取窗口；未返回观察不补造证明，观察存在也不代替内容对象校验。已验证响应必须对应影子快照、合法物理表示和单一模式，并具备正确格式的 Git 与内容摘要、非负字节大小；观察存在时版本标识必须匹配对应来源卡。

字节相同或不同与模式变化分别显示，模式缺失或无法证明显示未知。候选不升级为确认，文件身份与保存内容不证明运行实际输入输出。链接仅比较链接目标文字，不跟随链接。差异、HTML及命令均作为 React 文本展示；原 LF、CRLF、末尾换行和差异原字符串保留。两侧原字节合计最多64000字节，每侧最多2000行，输出最多64000 UTF-8字节，超限不截取片段冒充完整结果。不可用原因映射为中文，未知原因保留诊断。

比较采用既有认证请求。并发点击受到请求状态保护；改变选中版本、方向、截止、项目或页面版本使旧响应失效。401走统一登录；409保留两侧选择并要求主动读取最新列表、核对后再次比较，不自动换版本或重试。回包身份、证明或完整性异常不展示差异正文。

## 全量失败的根因与分页复验

实际版本接口按 `observed_at DESC,version_id` 排序，同次捕获时间相同，完整版本ID又取决于临时根身份。旧合成服务将28个填充文件和9个变更版本在同一次快照捕获，37条同时间版本超过每页25条；文件名中的 `a-` 不参与排序。比较后版本可排到第二页，旧测试仍假设它必在第一页，等待不存在于当前页的卡直到超时。不是产品丢版本，也不是两次捕获时间被毫秒排序合并。隔离旧冻结seed实际调用生产版本API，确认比较后同捕获37条、比较前同捕获9条，诊断日志单独保留，不计成功测试数。

修复仅修改独立合成服务、浏览器专项及本记录：先捕获before，再单独新增28条填充并捕获，最后应用after内容、模式与链接变化并捕获。没有修改已有观察或历史快照模式。新的9个after版本来自第三次实际捕获，稳定在首25条；before在第二页。测试断言最新同捕获恰9条、两侧实际页位置，逐项核对第一页25条及第二页22条ID与真实API全列表，选择后从第二页返回第一页再次核对双侧值和选中状态；原跨分页选择、原文、只读、方向与迟到响应断言全部保留，未增加超时或重试。

修复后首次六项专项为 `6 passed (15.8s)`；随后明确输出临时根与服务身份，再运行：

```bash
PATH=$PWD/../.tools/node-current/bin:$PWD/../.tools/bin:$PATH LD_LIBRARY_PATH=$PWD/../.tools/browser-libs/usr/lib/x86_64-linux-gnu pnpm exec playwright test tests/browser/version-diff.spec.ts --grep '真实保存字节在工作区删除后可比较' --repeat-each=10
```

实际为 `10 passed (1.2m)`。日志核对repeat索引0–9及十个不同服务进程、项目、根标识和临时工作区路径；不是同一服务重复读取同一页。after实际排名为 `[8,0,2,4,8,4,3,1,3,8]`，before为 `[46,39,41,39,38,46,46,46,40,46]`，全部真实跨页且选择保持。随后最终六项专项 `6 passed (15.7s)` 并重新生成七张图片；tsc退出0，ruff及格式检查通过。独立根日志为 `frontend-version-diff-pagination-repeat.log`，程序核对为 `frontend-version-diff-pagination-roots.log`。
