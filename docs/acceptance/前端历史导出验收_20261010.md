## 阅读条件与隐私

发生截止和获知截止必须是带显式时区的有效 ISO 时间，留空按生成包时刻读取。前端拒绝无时区、不存在的日期和非法时分秒，保留用户输入供修正。

阅读范围分为三个明确选择：所有范围省略 `scope`，完整已知范围发送全部字段和值，仅范围未知发送 `scope:null`。完整范围不接受空白、重复字段或缺值，不根据关键词猜范围。筛选始终使用输入原值；包中可能经过遮盖的范围不会回填或用于下一次请求。

默认 `include_evidence:false`，保留引用而不读取正文。用户勾选后只加入引用片段，经等长 UTF-8 字节遮盖；原库和原始引用摘要保持不变。可填写每行一条自定义正则，最多 32 条、每条最多 1000 字符；保留规则原话，由服务端判断正则语法，规则只用于本次下载。界面说明分享前应核对本项目的住院号、病案号或样本编号规则，没有承诺浏览器保存文件的权限。

## 下载、失败与迟到响应

ZIP 请求共用现有令牌、同源路径、无缓存设置和中止信号。200 响应需为 `application/zip` 且有 ZIP 文件签名；JSON、HTML 或错误字节不会当作下载文件。错误响应保留 HTTP 状态和服务端诊断。

400 保留条件供修正；409 禁止继续下载旧修订，主动读取最新版本后仍需再次点击，绝不自动重发；401 沿统一登录入口恢复。每个请求核对项目、当前页面、鉴权和完整阅读/隐私意图。切换项目、修改条件或取消等待后，迟到 ZIP 不会下载，旧 401 不会登出新项目。忙时禁止重复提交。

“取消等待”只停止本页等待，界面明确服务端生成可能仍完成。临时 `blob:` 地址在下载交付后定时回收，离开页面、下一次下载或点击失败时也清理，重复清理只回收一次。文件名由项目标识和读取修订生成，不接受外部路径。

采用现有“验收问答项目”和“验收问答项目二”，未改 `tests/frontend_server.py`。浏览器通过实际人工问题 API 写入合成 `ZY654321` 及 `contact-export@example.invalid`；不是实际临床资料。已有合成邮件、HTML 文字与多种记录状态继续用于验收。

新增 8 个语义单测及 9 个浏览器用例，保留原 65 单测、60 浏览器用例。真实本机 HTTP 检查默认 ZIP、显式正文、完整和未知范围、双时间、400、409、401及手机项目切换。测试用 Python 标准库只读 ZIP 成员，不解包或执行内容；核对 11 个成员和清单内每个文件的字节数、SHA256。默认包的记录集合与该小型项目真实图记录集合对应，图标记 `projection:false`，候选仍保持候选，证据引用没有 `text`。

显式片段验收核对导出正文 UTF-8 字节数与原文窗口相等，导出正文摘要正确，原文仍有合成编号、原引用摘要不变，包中合成邮件及自定义编号被遮盖。两项目读取均为真实接口，不因小屏的旧侧栏隐藏项目下拉而下载到错误项目。

延迟用例先取得真实后端 ZIP 或实际错误令牌的 401，再延迟页面交付；只模拟响应时序。错误文件类型用例模拟 200 HTML，证明不下载或执行它。临时地址的正常定时回收由真实浏览器检查，提前回收与点击失败由语义单测覆盖。没有使用外部模型调用来生成导出材料。
