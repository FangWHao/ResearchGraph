# Claude 事件父链界面验收

本轮开始于 2026 年 10 月 11 日，基线为 `f384f7db55411ffea03489c423488fa123b6f331`。沿已有前端授权，只扩充原文证据中的事件父链小面板；后端、主进度、设计决定及发布由父任务维护。

## 显示语义与缺口

事件父链随已有证据接口的同一次只读快照返回，不新增请求。源记录 UUID、父 UUID、旁支字段、来源实例与原记录首个内容块分别显示。多个内容块共享原记录声明；正文副本仍保留各自来源父链，不把正文去重误当父链合并。

旁支只有原记录明确的布尔字段才显示 true 或 false；缺失与非法保持未知。`parentUuid=null` 仅表示本条原记录明确为空父，与缺少字段分开，不证明根会话。匹配优先核对同来源文件，否则使用当前项目的等价声明组；同来源矛盾、歧义、循环、缺失或跨项目均不选择一个父原文。跨项目保留本条合法源声明，但不公开其它项目的引用。

等价父副本按事件编号及来源实例全部列出可见项，由用户按需要打开；界面不代选唯一副本。二十条之外明确提示省略。祖先检查保留多来源上下文、六十四步上限及其它终止状态，只描述已存元数据，不证明完整祖先历史或科学采用、使用、确认。

来源或项目元数据未完整登记时明确显示补记缺口。`metadata_incomplete` 表示相关旧元数据积压，不能据此判断无父、无循环或唯一父，也不生成父引用；直接父可核对但后续祖先元数据不全时，两者状态分别显示。旧接口缺字段保持未知，响应身份或引用结构异常时不显示导航。

所有导航只传事件编号。来源文件字节位置不用作原文对象内引用窗口；正文与 UUID 均为 React 文本，不执行 HTML、日志或命令。沿用既有证据面板的取消和鉴权处理，不修改 Codex 父线程面板，也不增加人工确认流程。

## 合成检查方式

`tests/event_chain_browser.py` 在临时目录生成合成 Claude JSONL，使用真实迁移、`scan_file` 和生产 API。先以旧版本二十一导入二百六十条记录，升级后二十二的补记分批执行；不删除观测，不修改原始事件。其它场景包括同 UUID／同正文但父声明不同的 fork 来源、多块记录、迟到父记录、二十一份等价父副本、非等价父、循环、六十五条祖先记录、无效或未知字段与跨项目。

浏览器先独立完成合成库准备，再启动 `127.0.0.1:9799` 服务，保留既有五秒监听等待和三十秒用例限制，不增加重试。服务由测试负责停止并删除自身临时目录。未读取真实完整会话、临床资料或密钥，模型调用为零。

原文另请求明确全文字节窗口，核对 UTF-8 长度及 SHA256；未给引用窗口时摘要为 `null`。迟到成功或 401 来自真实本地 API，再由测试路由延迟交付；测试传输有意忽略 AbortSignal，以检查组件取消后的迟到交付，生产取消逻辑不变。错误事件身份只由测试路由注入，不冒充真实后端记录。
