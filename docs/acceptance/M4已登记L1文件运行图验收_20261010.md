# 已登记 L1 文件运行图验收

日期：2026-10-10。范围：执行版 §2、§5、§8.2/8.3、§9/10/15 与原设计 §4/5。只验证已登记记录的完整图与读取一致性，不将报告视为实际全部输入输出，也不代表完整 M4 或 Atlas 正式试点通过。

## 行为与边界

- `rg l1-graph`、`GET /api/l1-graph` 和历史 ZIP 的 `graph.json.l1` 共用收集器与 Reader。五集合分别为节点、关系、观察、原件引用、未解析记录，完整遍历分页；节点身份由类型、记录与完整范围摘要确定。
- 文件版本、原生执行、候选运行清单、候选编辑、工作区快照和明确引用的同范围尝试分别保留。尝试全部内容版本保留，多版本不按 ID 猜当前事实。报告的重复端口各保留角色、序号与原 ID；未知 `null`、明确空 `[]` 和缺失版本分别展示。
- 原生请求、开始和退出依据全部截止内观察重算，再分页。候选报告退出码冲突不覆盖原生事实。输入输出关系只连接报告或候选编辑，不从任意命令猜完整运行 I/O；未知前像、调用 ID 歧义、缺失版本与快照超时留作缺口。
- 发生和入库双截止贯穿图、报告、文件观察、编辑与证据定位。范围仅沿明确清单引用；同路径不归属、不补齐其它项目或后来版本。当前文件的发现快照不成为旧字节捕获证明。
- `GET /api/l1-evidence` 按固定项目、双截止与修订打开原事件，UTF-8 字节窗口可续读；不加入后来派生文件或运行上下文。图查询不读取正文对象、当前文件或影子仓库，不联网调用模型，不写图缓存，也不执行资料中的命令。
- `l1_graph_complete=true` 仅表示已登记图集合完整返回；`l1_dependencies_complete=false`、`actual_io_completeness=unknown` 继续说明实际 I/O 未知。图和原文接口继承本地令牌、Host 与 Origin 边界，修订变化返回 409。
- 数据库版本 17 为编辑新增修订触发器，旧库已有编辑时推进一次修订；迁移失败回滚，保留原始事件与编辑。历史 ZIP 保持十一成员和原格式，新增图字段继续应用项目遮盖。
