# 只读 MCP 与状态卡验收

日期：2026-10-10。范围为 §2、§5.1/5.3/5.4、§6.5、§7.11、§10 和 M4 的 Agent 读取入口。使用合成库；不读取完整真实会话，不调用提取模型，不修改个人客户端设置。本轮实现五个只读工具与 context CLI，完整 M0–M4 和 Atlas 真实找答案时间仍未验收。

## 入口与预算

```bash
uv run rg --data-dir /已有数据库 context --project 项目ID --budget 2000
uv run rg --data-dir /已有数据库 context --project 项目ID --budget 6000 --scope data=v2 step=cnv
uv run rg --data-dir /已有数据库 mcp --project 项目ID
```

MCP 通过 stdio 提供 search/node/evidence/history/context，不打开端口，启动时固定一个项目。SQLite mode=ro、query_only 和对象库写入禁止共同保护应用数据；没有数据库或版本不符就退出，不在读取入口创建目录、建库、迁移或补缓存。HTTP GET 也改用只读连接，原有人工 POST 验收仍保留。

用户取消了 §7.11 的固定 1500 token 上限，普通工具按有限页长与字节窗口读取。context 默认 2000 token、允许调高，按优先级保留详情，超预算保留引用、独立状态及范围，再按实际保留条数给下一偏移；不能静默跳过一条。预算计算包含整个 rg-context 标记文本，MCP 协议封装在预算之外。

本地编码默认 cl100k_base，启动参数可改为 o200k_base。两份公开词表随包提供并验证正式 SHA256，读取不隐式联网；与官方编码对同一 Unicode、换行、数字及特殊标记原样文本的计数一致。它们不是 Claude/DeepSeek 的 tokenizer，提取模型的完整请求实测要求不变。来源与许可证见 rg/query/data/README.md。

## 语义与原文

发生截止 occurred_until 和已知截止 known_until 分别约束事件发生及记录时间；审核和替换只在当时已记录时生效。缺失或无时区的发生时间保留并标记，缺失记录时间的引用排除并按唯一 ID 报告。固定双截止与 expected_revision 可以续读；图变化时重新开始。

状态根据整个项目的符合截止历史和完整范围计算，随后分页，不依赖界面图的 2000 条限制。候选不会变成采用；人工确认决定不会确认方案、证据或运行。未知范围、未知发生时间和同刻冲突明确返回不确定；状态来源超过 20 个 ID 标记 partial，不能按首 20 条计算。问题的解决状态缺失时显示 unknown，不推断已经解决。

所有工具结果和工具执行错误带 rg-context 标记；源字符串尖括号转义后不能结束外围标记。再次导入会排除研究工具及标记内容。检索采用参数绑定和字面量匹配，事件搜索不猜统一范围，候选、驳回和修改前记录均保留明确状态。

C、S、E、V: 分别对应 claim_id、span_id、event_id、version_id。一次 evidence 只指定一种。原文从已复制对象读取，带实际 UTF8 字节窗口、窗口摘要和连续下一偏移；源文件删除仍可读取。损坏、超界和非 UTF8 引用不会给错误窗口或不前进的游标。文件观察按项目隔离，可从版本 ID 回到关联事件；保留原算法、候选状态和完整性边界，不读取当前文件补写历史。

## 协议依据与边界

依据 [MCP 版本与兼容](https://modelcontextprotocol.io/specification/2026-07-28/basic/versioning)、[stdio](https://modelcontextprotocol.io/specification/2026-07-28/basic/transports/stdio)、[工具](https://modelcontextprotocol.io/specification/2026-07-28/server/tools)、[缓存](https://modelcontextprotocol.io/specification/2026-07-28/server/utilities/caching)及[官方 Python 客户端](https://py.sdk.modelcontextprotocol.io/client/)。实际客户端首次检查发现新版 tools/list 必需缓存字段缺失，已修正并加入回归；现代请求不能继承旧协议连接的元数据。

只读保证针对应用数据，SQLite 可能维护 WAL 共享索引。普通查询分页而非固定 token 上限；长条目仍可超过 1500。异常响应不回显原件或请求。同步服务串行处理；大库性能、耗时读取的主动取消和完整工具吞吐控制仍需后续验收。候选写工具 propose_note 依赖尚未约定的 note 类型，没有以人工入口替代它。
