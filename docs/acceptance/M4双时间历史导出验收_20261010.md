# 双时间历史导出验收

本轮落实 §2、§10、§11 及原设计 v1 §9 的历史导出合同。所有执行材料均为合成数据，不读取完整真实会话、不外发研究记录、不调用模型，也不把本轮通过当作完整 M0–M4 验收。

## 交付行为

- `rg export --project … --output 新文件.zip --until 带时区时间 --known-until 带时区时间 --scope 字段=值`；同源令牌 `POST /api/exports` 直接返回 ZIP，不接收路径或保存服务端副本。
- 包内保留数据库版本、两个截止、完整范围、修订号、来源清单、算法与源码摘要、对象摘要、全部断言版本、状态事件、历史审核、图关系/共同输入端口/合并断言、证据引用、文件观察和候选运行报告。未解析端点及缺失信息保留；独立采用、证据、审核和运行状态不互相替代。
- 所有资料共用 SQLite 读取快照；全部分页收集，不采用界面 2000 条投影。晚到记录及截止外来源不回流，指定范围的物理版本与原生运行只经明确候选报告关联，不能证明实际 I/O 或文件归属。
- 默认没有引用正文、完整会话、二进制或环境副本。`--include-evidence` 只加入选定断言的证据片段，先验证原文摘要和 UTF8 字节边界，再遮盖整个事件后取片段，保留原始/导出摘要、字节恒等映射与遮盖范围。每次可指定临床正则；凭据字段另行清空。结构身份或字段名遮盖碰撞时拒绝发布。
- 默认引用包在 L0 对象丢失时仍保存定位，标 `not_read`；显式正文遇到缺失/损坏则不发布。`verify-export` 无需数据库，不解包或执行，核对十个成员的长度/摘要，拒绝重复、额外、越界名、链接、加密或缺失成员。校验不是签名或研究真实性证明。
- CLI 拒绝库内目标、祖先链接和覆盖，以同目录临时文件和独占硬链接发布。请求 0600 并报告实际权限；失败清临时文件，强杀时可能留下尚未发布的临时文件。实际 Windows ACL 和用户保存/分享副本不在这份校验的证明范围。

## 边界与安装包复验

34 个固定案例覆盖：106 条断言与 106 条证据无分页丢失、审核的已知截止、两个状态轴、候选不成为采用、完整范围与项目隔离、来源的独立双时间、循环关系与共同输入端口、原文与导出摘要及等长映射、临床正则、规范种子、凭据字段、转义 JSON 密钥、未知发生时间/UTC 偏移、UTF8 和摘要损坏、102 份报告/256 项 I/O、旧运行不借晚到退出、物理观察可见性、不读工作区、无效字段与修订冲突、WAL 并发写下的一致快照、原文缺失、身份/字段碰撞、并发目标保护、链接拒绝、包内篡改、实际 CLI 和 HTTP 200/400/401/403/409、逻辑库不变。

重新安装最终 wheel，以隔离解释器在仓库外执行：模块来自 `site-packages/rg/export/build.py`；已删除来源工作区的合成备份仍能导出全部 256 项报告 I/O，原生状态保持 requested，规范种子文本精确。默认没有正文，显式正文的临床编号与邮箱被遮盖，文字摘要一致。

在已写完临时 ZIP、尚未独占发布时实际 SIGKILL，返回 -9、目标文件不存在、证据库逻辑摘要不变；临时文件在 `/tmp` 实为 0600，同目标重试成功。真实安装目录 HTTP 200 ZIP 可校验；模型尝试为 0、schema 为 15。再删除整个证据库，独立 `verify-export` 仍校验十个成员，不重建数据目录。

另在实际 `/mnt/d` 发布合成 ZIP，独占硬链接可用、十个成员校验通过，但模式显示 0777；回执明确 `requested_mode=0o600`、`observed_mode=0o777`、`posix_private=false`。不能据请求的模式宣称 Windows 文件已私有化。

本地证据保留在忽略目录：最终测试/格式/类型日志、wheel 成员核对、安装目录强杀/重试/HTTP/离线校验，以及挂载目录权限观测。凭据、临床资料、真实会话、数据库、下载包与截图均不入仓库。前端验收见[前端历史导出验收](前端历史导出验收_20261010.md)。

完整语义图引擎、影响传播、大规模导出性能、项目级临床配置与完整隐私清除仍待实现或验收；Atlas 正式参考和真实质量门槛未改变。本轮不安装个人钩子或常驻服务，不执行会话中的命令。
