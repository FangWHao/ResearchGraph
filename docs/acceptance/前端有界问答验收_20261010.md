## 页面行为

新增“研究问答”导航。用户可点击“仅本地检索”，或通过“查找答案”先检索再按服务端模型配置继续回答。无需先人工复核候选，未配置模型和没有有效来源时保留本地检索能力。浏览器没有模型地址、密钥或预算输入。

首次远程使用先展示本地生成的实际遮盖输入、遮盖标记、来源条数与预览校验值。用户主动勾选后才能开启外发；说明明确覆盖整个项目的模型计数、自动提取、问答及后续新增资料。撤回许可后保留本地来源，并提示已发送请求可能仍在处理。

空范围表示检索所有范围；不会造出 `unknown=unknown`。完整范围按字段整体传递。发生截止和获知截止要求明确时区，页面同时展示检索版本与双截止。

封装内容只经 JSON 解析并作为 React 文本展示，原话中的脚本标签不执行。来源卡保留候选、确认、驳回、替换、范围、双时间、独立采用/证据状态与窗口边界。来源文件字节表示原始 JSON 行在来源文件中的位置，原文窗口字节表示证据对象内的位置；两者不混称引用位置。模型解释另标，不会确认候选或改写原文。引用可定位本次来源卡，再以同一事件、窗口起止和窗口 hash 打开既有原文面板。遮盖引文与本地明文不一致时有明确提示，不拿模型引文冒充原文 hash。

草稿与结果只在页面内存中按项目保存。请求按序号、鉴权代次、项目以及问题/范围/双截止/窗口意图核验；切换项目、停止等待或修改输入后的迟到回包不会覆盖新草稿。停止等待只取消浏览器等待，不宣称服务端模型已经停止。损坏回包与模型失败保留此前有效的本地来源；409 刷新后需重新主动点击，401 回到既有登录流程且保留草稿。

## 实际 HTTP 与模拟边界

浏览器使用本机 `127.0.0.1:8791` 的合成验收服务，两个项目为“验收问答项目”和“验收问答项目二”。本地检索、范围/双截止、预览、项目授权、撤回、原文窗口、版本冲突与鉴权均调用真实后端。

服务端模型提供方使用 `httpx.MockTransport` 模拟外部协议，真实 Provider、计数、Worker、项目权限与引用校验照常执行。模型坏引用、计数不可用、截断通过合成问题指令触发，后端真实判为不可用；这不代表真实外部提供方验收。没有外网模型请求、真实会话或密钥读取。

浏览器仅对未配置模型的 options、损坏回答字段与迟到响应做显式拦截。迟到用例先取得真实回答再延迟送达；损坏用例修改实际回答的记录字段，以验证格式错误不能清掉本地来源。截图中的预览、授权和成功回答均为真实本机 HTTP 与合成模型协议结果。

## 失败与修复

专项首轮为 6 项通过、2 项失败：一项断言误读既有原文 API 的 hash 字段，应读取 `event.quote_sha256`；另一项以整段精确文字查找段落内的“未配置模型”提示。修正断言后专项 8 项通过，耗时 12.0 秒。

完整首轮为 42 项通过、1 项失败，耗时 32.9 秒。新增两个问答合成项目令真实 `known_source_paths` 从 5 增为 7；更新健康页固定预期，继续保留登记来源、spool 与快照等完整对象断言。专项通过后增加损坏记录和同项目迟到意图用例，完整回归共 43 项浏览器用例、45 项单测。

初次页面接入时一次构建因辅助脚本使用相对路径的工作目录不符而报告尚未使用的页面导入；修正路径并完成接入后构建通过。该错误未触及后端文件。
