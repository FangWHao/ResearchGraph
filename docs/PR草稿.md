# 建立可追溯研究记录与本地复核工作区

主分支目前只有许可证，无法安装或运行 ResearchGraph。本次接入 Python 研究记录后端、React 本地工作区、中文执行规格、合成样本和自动化验收，沿用 Apache-2.0。

工作区提供问题与方案、复核队列、完整决定时间线、健康、字面量检索、原文字节证据和 React Flow/ELK 研究图。比如一个片段有 211 条候选，界面取齐 200 条 API 页后原子确认全部记录；另一窗口先改动时返回 409，刷新后重新复核。人工修改追加 confirmed 替换版并保留原记录和原文；新模型候选展示同一身份与范围的已有人工确认差异。节点和关系严格分 scope，发生时间未知或同刻冲突不任意推断当前采用；部分图和缺失端点不能折叠。

采集健康页补齐全库来源与 spool 回执/任务、当前项目的快照缺口和 UTC 模型阶段观测。等待或 running 记录不证明进程仍在运行；重叠快照标记不推算成功数。字段缺失、未知利用率和真实零值分别呈现；读取失败停止加载，局部重试成功后清除旧错误。手机表格支持键盘横向滚动，页面保持在视口内。

提取先实测完整请求 token，默认 128000 输入预算可调，引用程序登记的原始字节窗口。模型原行始终 candidate；§7.7 的确认由独立程序重读完整用户声明，核对对象、范围、理由和证据后追加可审计的 rule 动作，人工确认优先。截断、污染、超预算或校验失败结果作废。同会话/任务进程互斥，完整响应可恢复并入库一次，自身规则确认不使已完成会话缓存失效。追加助手回复只处理新事件，旧用户决定仅作上下文；不可变片段计划保存长正文的字节窗口和重试子片段，候选或无候选结果与完成状态同事务提交。中断后恢复覆盖并按原始顺序继续；人工失败默认不重发，显式 extract --retry-failed 重试。

跨会话链接逐对处理并保留进度，概览分页读取结构化记录并加防回流标记；监控保留每次尝试、UTC 用量、未结算预留、利用率/校验拒绝告警与覆盖缺口。旧库事务升级至版本 11，保留 L0、定位和尝试历史；旧缓存只有配置、完整前缀及项目证明匹配时才继承。采集支持显式来源的持久轮询与 spool 消费：原件和不可变回执先提交，日志游标完成后再确认；未知或未归属提示保留，消费分页轮转避免等待项阻塞后续。实际 SIGKILL 后恢复旧提示与新日志，不重复记录；备份包含回执原件。HTTP 只绑定 127.0.0.1，使用随机令牌、同源与静态目录校验，不执行会话命令。Python wheel 与前端静态资源分开部署。

rg-hook 原件先保存，异常静默退出 0，仅在明确根目录拍独立影子快照，不读会话、不联网、不调模型。示例不会安装到用户设置。快照保持用户 index 和工作区不变，保留原始字节与链接目标；大文件/嵌套仓库明确遗漏，超时/变化无有效提交。独立快照原件、追加历史和引用完整性检查支持提示先确认、原目录删除及备份恢复。本机公开源码 20 次引擎基准全部成功，p95 1426 ms，根目录模式改为异步并记录竞态；尚未声称实际客户端整条钩子验收通过。

运行与编辑证据从已保存 L0 离线派生，调用关联限定同一实际会话。无结果不是失败、stdout 退出码文字不冒充运行结果，冲突调用或退出码保留原观察并显示未知。Claude 报告的前后文本始终为 candidate；Codex 更新/删除只保存补丁，完整版本未知，新增也不补空白前版本。不可变事实与派生状态同事务，失败显式重试；恢复备份保留候选内容与补丁。前端证据面板可跳原始请求/结果，展示双时间、未知、候选版本、仅补丁和清单/正文上限；全库事件编号入口让未进入正文搜索的工具事件可直接打开。运行 I/O 版本仍未记录，命令仅阅读。

问题页新增人工研究问题入口，CLI `rg question` 与本地 HTTP 共用原子写入，文字、原文引用、人工身份和双时间一并保存。未指定范围保留 null，人工问题与直接人工决定允许这样追加修改，模型 schema 继续要求完整范围。UUID 重试只返回原记录；成功后丢响应或并发提交不会新增问题，相同编号用于不同内容返回 409，旧重试不撤销后续人工审核。虚拟输入不被当成本地日志路径、不重复提取。note 类型和客户端包装仍待后续实现。

人工决定补记支持四种动作，按整个项目有效对象和完整范围核对身份。唯一对象只确认决定，目标候选仍待复核；同名或未知对象保存 null 目标候选，在队列显式选择。对象分页不依赖图的 2000 条上限，普通、批量确认与通用编辑不能绕过歧义。选择追加人工替换、复核和独立原件，保留原动作、理由、范围与发生时间；未知范围不成为当前采用。人工问题、决定及对象选择共用跨操作 UUID，丢响应或并发重试不会新增事实，旧重放不撤销后来驳回。旧模型决定连续人工修改保留原 speaker/explicitness。日常自动采集与提取不以人工补记为前提，人工入口仅作可选补记和纠错，真实自动完成比例尚未验收。


省略会话的 `rg extract` 自动发现已归属且允许外发的会话并使用持久队列；`--watch` 接上扫描、spool、L1 和提取，新内容固定截止事件，后续追加进入下一任务。同数据目录系统锁及领取编号保护接管，强杀后保留未知用量、恢复完整响应而不重复入库；日额度等待下个 UTC 日，新内容与切回旧配置保留等待。审核变动本身不重排没有新增内容的会话，失败默认保留缺口、显式重试仅启动首轮。健康页显示七状态、项目/全库口径、分页与未知值；本次任务完成不代表事实确认或全部原文覆盖。系统常驻服务、自动串接关联/问答仍待后续。
