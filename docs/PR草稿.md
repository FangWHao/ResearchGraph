本机 Codex／Claude Code 的会话现在可以持续采集为有原文引用、审核状态和历史时间依据的研究决定史。Windows旧记录因路径语法丢失文件关联时，后台可核对已保存的请求与报告，追加路径证明并补登严格可重建的候选正文；历史读取按实际补齐时间展示。根目录身份也独立保存双时间观察，后来登记的Git信息不会冒充早期已知事实，旧登记保留发生时间未知的基线。

## 最终实现

- 本地项目创建、显式来源登记、增量扫描、轮换／残片／压缩／父子会话与注入排除；钩子只写spool和快照，原件保留。已有项目可追加根及明确开启同仓库工作树发现，跨项目片段归属与科研依赖迁移需核对完整范围。
- 提取／关联／概览持久队列、重启恢复、覆盖缺口、缓存与每日额度；明确外发许可后才调用模型，128k默认预算可调并前置实测。独立原话规则和人工审核与模型候选分开，模型失败时仍可导入与查证。
- 盘符／UNC／POSIX及逐记录目录定位，新旧L1请求和报告一致性核对，多步编辑保留原报告身份。已登记共同Git目录用于跨工作树检索，物理文件和版本分别保留；同版本候选另核对完整范围、算法和摘要。
- 根目录登记／元数据变更同事务追加不可变观察；CLI根清单及版本／运行／编辑／快照按双截止读取。L1旧路径补齐和根证明均不回写原历史或改变科研状态。备份、科学依赖闭包、共享物理来源保留和最后引用整项目清除接通。
- 问题、研究图、问答、原文检索、复核、物理版本差异和历史导出；L2语义图与L1文件运行图固定项目、范围、双截止及修订分页，折叠只影响视图。下游核对区分确认、候选及报告依赖，实际I/O未知仍明确标示。
- 桌面界面默认三个主入口，低频工具收起；首次创建只需名称、绝对工作区和采集开关。完整wheel包含界面，可从仓库外直接启动，无需前端工具。`client-install` 安装项目技能和MCP，`start` 管理本机后台，显式 `--extract` 才开启模型流水线；服务只监听127.0.0.1。
