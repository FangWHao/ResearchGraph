# 接入自动研究记录、本地问答与客户端技能

主分支只有许可证，无法采集或查询研究会话。本次接入 Python 后端与 React 本地工作区，让 Codex/Claude 会话能沿扫描、提取和关联链路整理成带原文引用的研究记录，并供用户或 Agent 分页读取、按有限原文回答研究问题。项目接入包生成两种原生客户端技能和只读 MCP 配置，明确调用的人工问题/决定复用同一 CLI。

采集保留追加原件、未知类型与覆盖缺口，spool 与快照独立恢复，不执行会话命令。持续提取先按提供方实测完整请求 token，默认 128000 输入可调；持久任务固定截止事件，强杀可接续，每日额度等待下个 UTC 日。新增内容进入后续任务，失败默认保留缺口；模型原行始终 candidate，截断、超预算和污染结果作废。独立原话规则与人工审核另存，未知对象或范围不会成为当前采用。

本地界面提供项目、问题、可选人工补记决定、分组复核、双时间线、原文字节窗口、运行/编辑证据、持续提取健康与 React Flow/ELK 图。例如片段的 211 条候选跨页取齐后才原子确认；另一窗口先修改则返回 409。人工修改追加替换，UUID 重试不产生第二份事实；同名对象显式选择，目标候选不会被决定同时确认。HTTP 仅监听 127.0.0.1，使用随机令牌及 Host/同源校验。研究问答先本地检索，再根据服务端配置生成解释；首次远程使用显示实际遮盖输入，主动开启整个项目的计数/提取/问答及新增资料许可，可撤回。旧预览重验摘要，模型失败保留来源，项目或问题意图变化后的迟到结果不能覆盖新页面。

Agent 入口提供固定项目的五个只读 MCP 工具和 context CLI，不建库、迁移或写应用缓存。发生与已知双截止保留当时审核和修改状态；采用、证据从完整符合截止的历史计算，再分页，时间冲突与未知明确保留。原文窗口带 UTF8 位置、摘要和下一字节偏移，源文件删除仍可读。所有研究文本带防回流标记，源关闭标签不能逃出包装。

client-pack 只读生成 Codex/Claude 的三个技能和 stdio 配置，不覆盖已有输出、不改个人设置。上下文默认允许自动选用；人工 question/decide 仅明确调用，JSON 传原话且固定项目，保留 UUID 幂等、版本冲突及歧义候选。参数数组不经过 shell；包包含本机绝对路径，安装时按中文说明合并已有配置。

用户已取消 MCP 固定 1500 token 上限；查询保留分页，状态卡按调用方预算本地精确计数，默认 2000、可调高。两份正式编码词表随包校验，查询不联网，不冒充 Claude/DeepSeek 的计数。新版逐请求协议与旧初始化均由官方客户端实际连通。

ask CLI 先检索最多 12 条校验原文，再由已有执行器生成逐条带引文的解释；无结构化记录可检索原件，明确范围下不猜原件归属。retrieve-only 只读且不联网；没有有效证据零调用，模型失败保留检索。权限、完整请求实测、日额度及截断/污染丢弃继续执行。回答整体防回流、仅为模型解释，不写研究 claims；引用存在不证明解释正确。
