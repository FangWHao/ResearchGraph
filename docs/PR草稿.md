# 自动记录研究决定史并提供整项目清除与保存版本差异

主分支仅有许可证，缺少研究会话采集与查询入口。本次增加 Python 后端和 React 本地工作区，把显式登记的 Codex/Claude 增量会话整理为带原文引用、完整范围与双时间的研究决定史。扫描、spool、离线L1派生、候选提取、关联和结构化概览按持久队列接续；模型完整请求先实测token，默认128000可调，项目默认禁止外发，模型输出保持候选。

文件版本页新增两个明确版本的保存字节比较，CLI与本地HTTP共用只读查询。双截止和修订约束捕获观察；比较核对复制正文的长度、SHA256、Git blob摘要、合法模式和实际选用观察。工作区及影子Git移除后仍能从保存对象比较。字节差异、模式变化与候选状态分别展示，链接只比较目标文字；不读取当前文件补旧内容。UTF-8统一差异保留CRLF、U+2028正文与无末尾换行，来源不支持、对象损坏、二进制、编码无效或超限均明确不可用，不返回部分正文。两侧原字节合计64000、每侧2000行、差异输出64000字节。

声明与语义图来源增加只读 UTC 六位微秒时间字段，原始双时间和原文不变。前端据此分清同一毫秒内的事件先后；真正同刻相反的采用或证据显示冲突，缺失、无时区、非法日期与 UTC 越界显示时间未知。未知范围的证据需复核，候选、驳回和替换继续隔离；时间诊断不会进入人工可填写的科学证据枚举。

Codex 原生补丁开始/结束按同会话唯一调用核对；现代结构化回执允许 stdout 为空。新增后与删除前全文分别展示为工具报告候选，另一侧未知；更新/移动仍保留补丁。失败、元数据矛盾、缺开始、重复及迟到重复 ID 明确保留缺口；迟到歧义不改旧事实，较早已知截止仍保留当时关联。候选全文不能用作物理字节比较，不读取当前文件补历史。

已有项目可追加本机仓库、worktree、数据或别名根目录，保存登记时的 Git 独立／共同目录及本地配置 URL 摘要。只读清单支持分页与修订；相同远端或共同目录不合并项目，重复登记不覆盖旧身份。旧库原子升级到 schema18，不扫描旧路径；备份和整项目清除屏障覆盖新登记。手机布局显示原有唯一项目选择控件，390 宽可以直接切换；复用原 App 状态、草稿和迟到响应隔离。

已包含的功能：

- 流式采集与未知记录保留、镜像和压缩回放排除、离线钩子、影子快照、大文件完整摘要与读取窗口、候选运行清单和报告I/O。
- 持久任务、尝试历史、额度、缓存与强杀恢复；完整请求计数、超预算/截断/压缩作废；规则原话确认和可选人工复核。
- 本机令牌和Host/同源校验、CLI、五个只读MCP及两种客户端接入包；问答先检索、预览后授权、逐条引用核对。
- 问题、复核、双时间线、研究图与完整登记L1图、原文字节窗口、运行证据、健康、物理版本和历史ZIP；图折叠保留重要历史及每条边界证据。
- 项目临床正则共用于模型和导出；整段遮盖后切窗，规则变化使旧预览和缓存失效。
- 整项目只读归属预览、独占清除与中断恢复、无原文回执和重导入屏障；共享字节保留，未知归属和不安全路径拒绝执行。最终屏障删除失败也保持待恢复状态。
