# 自动采集研究会话并记录文件版本与决定证据

主分支只有许可证，缺少研究会话采集和查询入口。本次接入 Python 后端及 React 本地工作区，将 Codex/Claude 会话整理成带原文引用、范围和双时间的研究决定史；登记来源后，持续扫描、spool、L1 派生、提取、关联及结构化概览按持久队列接续。系统锁、领取归属、UTC 额度和不可变历史支持强杀恢复；模型前完整请求实测 token，默认 128000 可调，项目默认禁止外发，模型输出始终候选。

文件队列保留快照 Git 原字节/模式与大文件完整 SHA256 读取窗口；缓存沿用原读取窗口，当前观察不回推旧快照。新增离线运行清单记录明确输入、脚本、补丁、环境、输出版本及参数/种子/起止时间/退出码。原件、候选报告、I/O 与 UUID 回执原子追加；未报告与明确空列表分开，报告不覆盖原生执行事实或证明实际完整性。运行/版本晚到时只按同项目精确 ID 读取解析，不修改历史；版本和尝试可反查候选关联。

本地界面提供问题、问答及外发预览/撤回、可选人工补记、复核、双时间线、原文/运行/编辑证据、物理版本、健康与研究图。运行证据新增候选清单、退出码冲突、明确版本和未知字段，并支持固定修订的清单/I/O 续页；冲突保留原列表，迟到响应隔离。HTTP 仅 127.0.0.1，保留令牌及 Host/同源校验。五个只读 MCP、离线状态卡和 Codex/Claude 项目接入包保留；R: 运行状态只从双截止内不可变观察重算，分页不改变状态。用户已取消固定 1500 token 响应上限，条目和原文仍分页，状态卡采用本地精确可调预算。
