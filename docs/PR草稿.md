# 建立可追溯研究记录与本地复核工作区

主分支目前只有许可证，无法安装或运行 ResearchGraph。本次接入 Python 研究记录后端、React 本地工作区、中文执行规格、合成样本和自动化验收，沿用 Apache-2.0。

工作区提供问题与方案、复核队列、完整决定时间线、健康、字面量检索、原文字节证据和 React Flow/ELK 研究图。比如一个片段有 211 条候选，界面取齐 200 条 API 页后原子确认全部记录；另一窗口先改动时返回 409，刷新后重新复核。人工修改追加 confirmed 替换版并保留原记录和原文；新模型候选展示同一身份与范围的已有人工确认差异。节点和关系严格分 scope，发生时间未知或同刻冲突不任意推断当前采用；部分图和缺失端点不能折叠。

采集健康页补齐全库来源与 spool 回执/任务、当前项目的快照缺口和 UTC 模型阶段观测。等待或 running 记录不证明进程仍在运行；重叠快照标记不推算成功数。字段缺失、未知利用率和真实零值分别呈现；读取失败停止加载，局部重试成功后清除旧错误。手机表格支持键盘横向滚动，页面保持在视口内。

提取先实测完整请求 token，默认 128000 输入预算可调，引用程序登记的原始字节窗口。模型原行始终 candidate；§7.7 的确认由独立程序重读完整用户声明，核对对象、范围、理由和证据后追加可审计的 rule 动作，人工确认优先。截断、污染、超预算或校验失败结果作废。同会话/任务进程互斥，完整响应可恢复并入库一次，自身规则确认不使已完成会话缓存失效。追加助手回复只处理新事件，旧用户决定仅作上下文；不可变片段计划保存长正文的字节窗口和重试子片段，候选或无候选结果与完成状态同事务提交。中断后恢复覆盖并按原始顺序继续；人工失败默认不重发，显式 extract --retry-failed 重试。

跨会话链接逐对处理并保留进度，概览分页读取结构化记录并加防回流标记；监控保留每次尝试、UTC 用量、未结算预留、利用率/校验拒绝告警与覆盖缺口。旧库事务升级至版本 7，保留 L0、定位和尝试历史；旧缓存只有配置、完整前缀及项目证明匹配时才继承。采集支持显式来源的持久轮询与 spool 消费：原件和不可变回执先提交，日志游标完成后再确认；未知或未归属提示保留，消费分页轮转避免等待项阻塞后续。实际 SIGKILL 后恢复旧提示与新日志，不重复记录；备份包含回执原件。HTTP 只绑定 127.0.0.1，使用随机令牌、同源与静态目录校验，不执行会话命令。Python wheel 与前端静态资源分开部署。

rg-hook 原件先保存，异常静默退出 0，仅在明确根目录拍独立影子快照，不读会话、不联网、不调模型。示例不会安装到用户设置。快照保持用户 index 和工作区不变，保留原始字节与链接目标；大文件/嵌套仓库明确遗漏，超时/变化无有效提交。独立快照原件、追加历史和引用完整性检查支持提示先确认、原目录删除及备份恢复。本机公开源码 20 次引擎基准全部成功，p95 1426 ms，根目录模式改为异步并记录竞态；尚未声称实际客户端整条钩子验收通过。
